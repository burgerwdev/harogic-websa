# 原生 IQ 与协议测量

[文档](../INDEX.md) · [English](../../en/reference/SNR.md)

## 定义与接口

原生接收器通过 SDE2 发送 `rf-measurement`，同时在 `processing_runtime.observed_receiver` 中提供最新 `rf_measurement`。测量继承事件封装的接收器 UID、服务 ID、细信道 ID、采集 epoch、处理代次和样本时钟。历史 FT8 解码记录描述原来的发射突发，不表示当前信道读数。

| 指标 | 定义与单位 | 带宽与测量位置 | 方法与有效条件 |
|---|---|---|---|
| RF SNR | `10 log10((Pchannel − N0 B)/(N0 B))`，dB | `band_low_hz` 到 `band_high_hz`，相对调谐频率；在解调、AGC、静噪、降噪和 EQ 之前 | 固定 Hann/Welch 分析；**有条件估计**，假定稀疏占用及可叠加的平坦背景。分子包括所有带内信号及其他电台；背景可能包含无法分离的干扰。 |
| FT8 SNR | 解码音调功率扣除匹配滤波器背景，再除以 `N0 × 2500 Hz`，dB | **2500 Hz**；抵消前的原始 IQ，每个完整符号的中间 75% | 已知 Costas 同步及 CRC 解码数据音调；六个偏移 ±5/7/9 个窗频率 bin 的 Hann 滤波器估计局部背景；不再使用同步评分乘 0.5。 |
| FAC 加权 MER | `−10 log10(Σ |H|² |Y/H − Dnearest|² / Σ |H|²)`，dB | 均衡后的 FAC QPSK 单元，平均一帧；附带的 DRM 标称占用带宽是上下文，不是 MER 的积分带宽 | 包含噪声、干扰、失真和均衡误差；低 MER 存在最近点判决偏差。不是 RF SNR。 |
| FAC 判决 SNR | FAC MER 加 `10 log10(avg_cell_power × Ncar × Δf/Bnominal)`，dB | DRM30 占用带宽；DRM+ 为 **100 kHz**，不能套用 DRM30 占用码零的 4.5 kHz | 仅在**平坦白噪声信道**下解释为噪声比。MER 低于 10 dB、尚未 FAC 锁定、当前 FAC 失败或误差低于数值分辨率时不可用；每帧均清零累计，包括零误差帧。 |
| WFM 导频对比度 | 保留的平滑 `20 log10(A19k/A21k)`，dB | 鉴频复合信号经抗混叠及抽取后；单极点双边 ENBW 为 `Fs α/(2−α)`，50 Hz 极点对应约 157 Hz | 平滑时间常数 2 s；是导频 SNR 的诊断近似，没有进行功率噪声扣除，不表示 RF 或节目音频 SNR。该统计不控制监听增益或降噪。 |
| 外部报告 | 原始数值、单位和 provider | 由 provider 定义 | 外部算法和原始输出不变。GPS 逐卫星 C/N₀ 保持 **dB-Hz**。 |

原生测量携带 `metric_type`、`unit`、`reference_bandwidth_hz`、`location`、`method`、`averaging_seconds`、`state` 和 `reason`。RF 还提供观察时长、FFT 间距、窗 ENBW、平坦通带、ADC 满刻度平方单位的线性功率、可用参考比例、统计不确定度和最长有效年龄。不可用值为 JSON `null`；保留负数 SNR。旧 DSP/WASM 数字接口用 NaN 表示不可用 FT8 值，原生 JSON 将其序列化为 null。

没有干净参考的任意语音、音乐或图像，不宣称测得精确音频 SNR。已知测试音 SNR/SINAD/THD 仍是独立台架指标。Wiener、DeepFilterNet 内部估计及 DRM Wiener 正则化不作为 RF 读数或实测音质改善量。

## RF 分析与限制

复数双边 PSD 为 `|FFT(xw)|²/(Fs Σw²)`。边界 bin 按实际覆盖比例积分，使用真实 IQ 采样率，不使用取整音频时钟。周期 Hann 的 ENBW 为 `1.5 Fs/N`。该归一化守恒复数功率，不重复除以相干增益或 ENBW。

上游 FIR 的已知平坦通带来自实际基带计划。噪声参考避开四个边缘 bin 及 Hann 泄漏邻域；排除强频谱分量后，至少需要 64 个 bin、60% 可用参考，并要求八个频率区间都有参考且均值相差不超过 1.5 dB。不读取受抑制的阻带作为底噪，也不逆补偿深度衰减。真实信道 FIR 的合成测试验证滤波后的功率；这不是对任意射频硬件频响的校准。

纯噪声、低于三倍标准差分辨门限的信号、参考不足、宽带占满、背景或频响不平坦、严重泄漏及过载返回不可用。**仅凭 IQ 不能识别与噪声无法区分的宽带干扰。** 即使读数有效，也属于有条件估计。WFM、DRM 或任何占满平坦通带的信号可能没有可识别背景，因此没有 RF SNR。本阶段没有新增更宽的并行采集，也没有为取得保护带而改变解码、录制 IQ。

校验覆盖白色高斯噪声中孤立或稀疏信号的输入 RF SNR **−10…35 dB**。考虑 1 dB 误差余量，边界读数允许略微超出；−11…36 dB 以外返回不可用。`uncertainty_db` 是近似一倍标准差的采样不确定度，不是硬件校准结果或保证的置信区间。固定测试是可重复校验，不是完整的统计认证。

每信道使用 512～4096 点、32 个不重叠窗，最多每秒 64 次 FFT，复用 FFT 存储，不增加队列。窄信道平均时间更长：2 ksample/s、250 Hz 带宽时观察 65.536 s；390625 sample/s、100 kHz 时约 0.5 s。有效平均时长与观察时长均会报告。RF 超过两倍观察预算加 0.5 s 后失效，包括浏览器数据流停止的情况。换频、带宽/采样率/平坦通带变化、采集重启和样本中断会清除不兼容历史；本地音量不清除 RF 历史；硬件增益重配置建立新的采集身份。拒绝信道 IQ 中可见的削顶，但不能证明上游被滤波掩盖的削顶不存在。

## 重复验证

```sh
cargo test --release -j 1 --manifest-path backend/Cargo.toml --lib rf_ -- --nocapture
cargo test --release -j 1 --manifest-path dsp/core/Cargo.toml --lib snr_measurement_tests -- --nocapture
cargo test --release -j 1 --manifest-path dsp/core/Cargo.toml --lib decision_metric_validation -- --nocapture
python3 tools/bench/compare_ft8_snr.py --reference-bin /tmp/wsjtx/usr/bin --output /tmp/ft8-snr
```

可选参考工具需要 NumPy 和独立的 `jt9`、`ft8sim`。本次使用 Debian WSJT-X **2.7.0+repack-1**，仅解包而不安装到系统。由 `ft8sim` 生成 GFSK，按已知有效突发功率加入固定种子的 AWGN，向双方提供完全相同的量化样本，并保存哈希、参考输出和原生 CSV。−20 dB 时原生搜索未解出该输入，因此测量测试使用 WSJT-X 确认的码字与独立已知的符号位置。−24 dB 时该噪声实现连 WSJT-X 也未解出；工具记录该情况，不宣称完成解码器对比。搜索灵敏度与 SNR 精度分别验证。

2026-11-10 实测：

| 验证 | 结果 |
|---|---|
| RF 24 组合：2/12/48.828125/390.625 ksample/s；250/3000/12000/100000 Hz；−10/−5/0/10/25/35 dB | 最大实测误差 **0.162 dB**；验收目标 <1 dB |

| 真实细信道 FIR，15258.7890625 sample/s；频偏与衰落 | FIR 前输入 −5 dB，测得 **−4.964 dB**；衰落平均真值 1.761 dB，测得 **1.669 dB** |

其他回归覆盖分块一致性、纯噪声、增益/AGC/静噪/降噪独立性、多信道隔离、换频失效、真实 FIR 响应、频偏、衰落、过期和过载。显示 FFT 点数/窗、频谱缩放、瀑布和本地音频控制都不进入测量器配置及数据路径。自然电台接收不能建立绝对 SNR 真值；精度验证使用已知注入 IQ。

定义依据：[WSJT-X 指南的 2500 Hz 参考](https://wsjt.sourceforge.io/wsjtx-main_en.html)、[WSJT-X 解码音调估计](https://github.com/WSJTX/wsjtx/blob/master/lib/ft8/ft8b.f90)、[ETSI TS 102 349 的 FAC 加权 MER 与接收机 SNR](https://www.etsi.org/deliver/etsi_TS/102300_102399/102349/04.02.01_60/ts_102349v040201p.pdf)。原生 FT8 使用自己的实际滤波器 ENBW，不照搬 WSJT-X 的固定 −27 dB 偏移或显示下限。

测试工具附带机器可读的[验证结果与参考哈希](../../../tools/bench/snr_validation.json)。前端全套通过 2122 项，后端库与服务检查分别通过 154 和 400 项（依赖硬件或模型的项目仍明确忽略），DRM 通过 92 项，FT8 单元检查通过 30 项，参考、灵敏度与抵消回归通过 8 项。负载稳定时，既有 FT8 单槽耗时检查以 **3.044 s** 通过；并行编译和 UI 测试时曾出现 **5.690 s**，因此这不是实时最坏情况保证。真实 SAN-90 服务已使用新二进制重启，并精确恢复接收配置。切换显示 FFT 32768 → 65536 → 0 后，细信道身份、12 kHz RF 带宽和 1024 点 RF 分析保持不变；当前自然接收因噪声参考受污染而正确返回不可用。

## 实际广播与音频连续性核对

101.7 MHz 音爆排查的[测量记录](../../../tools/bench/fm_audio_diagnostic.json)保留了后端 AUD2 PCM、浏览器连续音频节点输出及历史版本对照的方法和限制。48/44.1 kHz 下，计入实际播放时钟校正及线性插值后，受控 Chromium 的播放节点与后端波形残差峰值分别为 **3.73×10⁻⁹ / 1.49×10⁻⁸**；48 kHz 最终 EQ/压缩器输出经固定增益和 288 帧延迟对齐后的残差 RMS 为 **1.80×10⁻⁹**。这些是链路波形一致性误差，**不是音频 SNR 或音质改善量**。没有采集用户原有浏览器会话的物理声卡输出。

抽取抗混叠修复前的版本与 v1.10.3 对同一 IQ 的无 AGC 输出完全一致。鉴频内核还与 SDK `ADM_FMDemod` 核对，RMS 差约 0.0014 Hz；原始 SDK IQ 绕过 PFB 也有包络深陷和鉴频尖峰。这些结果不能单独判定其物理来源。

另已复现并修复立体声分块缺陷：IQ 与 IQ/2 两路重采样器在块边界可能相差一帧；补零或丢弃差分帧会制造跳变。现在在联动 AGC 前保留有界的未配对帧，只输出配对数据，换台时清空。回归覆盖实际分数采样率、44.1/48/192 kHz 输出、1/17/9765/11165/12180 点分块及换台。原始 12180 点广播分块未触发此缺陷，因此不把这项修复当作该音爆主因的证据。

进一步修复了鉴频复合信号直接 2 倍抽取的混叠缺陷：带外分量会折叠到导频或立体声差分载波附近，再变成可听伪音。抽取前增加 33 抽头半带 FIR；用整数单声道延时及 33 抽头分数延时对齐两路，保留高频立体声幅度。325520.8333 → 48000 sample/s 时额外延时为 19 帧，约 0.396 ms，计入 AUD2 时序；清空、分块及滤波器启动均包含新增状态。输入 IQ 不变。300.480769/325.520833/488.28125 ksample/s、44.1/48 kHz 输出的已知带外伪音测试要求至少 50 dB 抑制。该数字是合成伪音抑制，不是广播音频 SNR 改善量。

用户确认两份前后端录音均有同类噪声，另一台收音机使用相同天线正常；长线有噪声而 YouLoop 无此反馈。两天线及实时增益试验录到的是不同节目，禁止逐样本相减或用音频 RMS/峰值推导精确改善。已测试参考电平 0/−20/−40/−50 dBm、前放、IF 档位、高线性及衰减，并恢复配置。增益试验未证实能消除原异常，不能据此断言前端过载。官方资料说明 Auto 前放约在 −30 dBm 以下启用；提高 IF 档位会在固定总增益下降低 RF 增益、改善线性并提高噪底，参见 [SAStudio 前放说明](https://www.harogic.com/wp-content/uploads/2026/08/HAROGIC-SAStudio4-User-Guide-V4.55.64.pdf)及 [HTRA 增益映射说明](https://www.harogic.com/wp-content/uploads/2026/08/HAROGIC-HTRA-API-Programming-Guide-V0.55.100.pdf)。用户在修复后反馈噪声明显改善、基本听不出来；这是主观接收验证，不是精确音频 SNR 改善量。IQ 深陷的物理来源仍未确定。音频修复范围是 WFM 专属支路；统一 RF 测量适用于各接收信道。

cargo test --release -j 1 --manifest-path dsp/core/Cargo.toml --lib analog::
