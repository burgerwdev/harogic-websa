# 带宽内扫描与识别

信道工作台旁带框的 `i` 图标打开“扫描／识别”浮窗，不自动启动扫描。开始/暂停控制共享的连续扫描；隐藏浮窗不停止后台扫描，但会结束临时试听；收起和弹出只影响视图。选区识别可单独使用，横向频段同时显示在频谱和瀑布上，松手提交，Esc 取消；瀑布与冻结图均识别当前 IQ，不回放历史 IQ。`I` 仍用于 IQ 录制。

开始扫描后默认按预算识别稳定候选，可在更多设置中关闭自动识别。发现按实际输入速率选择独立 65536／131072／262144 点 Blackman–Harris FFT，将 bin 间隔控制在 250 Hz 以内，使用四段 50% 重叠 Welch 线性 PSD，默认 5 次/秒。低旁瓣窗抑制强载波泄漏把邻台连在一起，PSD 仍按窗能量归一化以保持功率。62.5 MS/s 时 bin 间隔为 238.42 Hz，不改变共享采集几何或额外占用接收信道。连续性错误或资源压力下跳过整块、降速或暂停；没有全带连续短突发捕捉承诺。频道表按频率窗口积分线性功率，至少需要 8 个 FFT bin；不足时缩小实际采集带宽，显示放大不增加分辨率。高于本底是检测裕量，不能当作 RF SNR 或未经标定的 dBm。观测命中率只统计实际观察。

相邻片段使用固定合并间隙，不随已合并宽度扩大，避免一串短波电台连成无法探测的宽频带。超出单路通带的候选保留为不可用，原因是 `analysis_passband_limit`；界面提示缩小到具体信号，并阻止提交无法容纳的试听／加入配置。这是单个候选的分析限制，整个发现选区仍然有效。可选的 FM 宽导频窗口若无法准入，会回退到原分析宽度；PFB 通带、速率、成本和正式信道准入保持原样。

本底按每个 RF 频率附近估计：使用 ±750 kHz 邻域的顺序统计量，并留出 ±12 kHz 保护区，替代相对于全带最安静区域的上限钳制。20% 分位按四段噪声功率平均的统计特性校正到均值（约乘 1.7416），参考锚点在对数功率上插值。每次使用当前观察的局部本底，噪声升高时不再冻结旧的低本底。参考单元可延伸至搜索选区附近，因此仅改变选区不会改变同一频点的参考；既能跟随频率相关的噪声起伏，也不直接拿密集电台频段的平均值当本底。

未发现谱峰且整个请求范围无法由单个探针采样时，返回 `no_signal_detected`，不创建选区候选或探针。窄选区仍允许直接测量低于发现门限的 IQ，并以 `requested_window`／`not_detected` 标记。

识别优先旁路兼容、解调前的既有基带 IQ，否则借用一个空闲非 Current 槽。较宽的旁路 IQ 仍通过既有计划 DDC 做本地区域滤波和降采样，不能把邻频信号交给特征分析。观察分为 160、400、800 毫秒三个检查点；强 AM 或广播 FM 只有在前后两段独立数据的证据一致时才提前完成，其余继续收集同一连续 IQ。纯载波保留完整观察，避免把 AM 讲话停顿过早建议为 CW。采样间隙重置检查点，不拼接间隙两侧数据，也不延长原有 2 秒租约；每份 IQ 仍最多 8 MiB。特征按需计算，FM 导频已成立时不计算数字调制特征。识别使用已测线程 CPU 时间记账，平均预算为单核的 1/11，最多积存 20 毫秒 CPU 突发额度；取消或重新选区不清除 CPU 欠账。接收压力仍优先触发降速或暂停。

候选不占正式名额，停用的正式定义仍保留名额；最多只有一个临时探针。临时 DDC 使用同一几何/成本准入，正式创建前等待同步有界退役回执，失败时不复用未释放的槽。满 16 路仍可发现或复用 IQ，其他识别显示等待资源。

发现裕量不足提前完成门限的候选直接等待完整 800 毫秒，省去无法形成提前结论的短窗计算；它们仍可得到完整观察下的调制结论。

录制已排队和执行中的数据达到原预算的四分之一，或最早未完成数据达到 250 毫秒时，扫描提前退让；录制的字节／条数／时长硬上限保持不变。扫描不等待录制锁或磁盘 I/O，压力消退后按现有冷却恢复。

瞬时占用宽度不等于 FM 的完整分析带宽。对至少 40 kHz 的候选，选区和采集几何允许时，单一探针可保留 180 kHz IQ；原窗口先分析，只有未知／FM 类候选在宽窗口中同时满足导频、低包络变化及中心仍在原测量窗口内时，才采用宽窗口结论。AM、FSK、PSK 等原结论保留；已有窄 IQ 仍可复用，不为宽检查额外占槽，采样和计算继续受原预算约束。推荐中心细化后，后续探针也缩小到原分析范围内。

检测先平滑线性谱、扩展至本底附近、合并相近片段，避免 AM 边带和 FM 组分被拆开。测得的载波峰宽与实际分析通带分开：窄峰分析为音频边带保留至多 12 kHz 空间，同时严格限制在用户选区内；加入 AM 信道默认至少 12 kHz。AM 使用可容忍频偏的载波谱线和包络特征；FM 使用包络/鉴频特征并在三个独立窗口内搜索 18.85–19.15 kHz 导频，不要求精确落在 19 kHz 单点。AM 载波线、WFM 平均鉴频偏移会细化接收中心；更新推荐代次，同时保留测得频率边界。

首批形态为载波、AM/FM 类、2FSK/4FSK 类、PSK 类或未知；不自动把调制形态命名为 DMR、P25 等协议。FM 19 kHz 导频是专用特征；已运行解码器的有效 RDS 组、DRM FAC、FT8 消息可提供独立协议证据。不会批量启动 provider。`label` 表达调制形态，`protocol` 只来自专用结构化证据；`receiver_available` 表达建议接收模式可用性，`decoder_available` 单独表达已确认协议的解码器可用性。接收建议变化会推进候选代次，普通电平更新不会。可信状态不是准确率；不确定结果可加入 IQ 信道，明确选择音频模式后可监听。加入与复用继续走接收机预检、身份及资源检查。

## 找到、试听、保留

默认“发现信号”寻找未知频率。表格每行直接提供“试听”和“加入”：试听优先复用兼容已有信道，否则借用一路正常准入的临时接收机，切换时复用该路；停止或隐藏浮窗后释放。默认勾选“试听时静音其他频道”，只改变本地扬声器路由，不暂停其他接收、解码或录制。取消勾选可以与原混音一起试听。试听结束恢复原路由、独听和跟随设置；用户修改或录制接管的接收机不会被自动删除。点击“加入”可就地保留正在试听的接收机，不重建 IQ 流，并按现有混音规则启用音频。

“试听／加入模式”仅作用于所选结果，用来选择如何听或接收，不改变识别结论；自动使用建议模式。仅 IQ 不播放音频：加入后可在工作台录制、导出和分析基带。未知信号可以手动选 AM、USB 等音频模式试听，或直接加入 IQ。

搜索支持 MHz、kHz 和类型文字，类型／状态筛选只改变列表；点击频率、带宽、类型或门限裕量列标题排序，指针或键盘在表内操作时锁住行序，避免功率变化导致按钮跳行。清除结果不会删除正式信道，连续扫描运行时新命中会重新出现；更多设置可以仅清除非活跃结果。清除后的旧分析回包不能恢复已删记录。

“固定频点测量”即原频道表：已知频率、间隔及带宽时，并行积分每个窗口的功率和观察活跃程度；例如按 100 kHz 间隔检查几个固定频点。不会自动创建接收信道。普通找台使用“发现信号”或选区即可。识别只在有效的非负 RF 频率范围内产生候选，跨越零频的 IQ 窗口不展示负频镜像。

## HTTP

- `GET /api/sdr/scan`：共享会话、源身份、范围、最多 128 行摘要、探针占用及观察/CPU/跳过统计。候选上限 256，识别队列上限 32。摘要不包含详细证据。`bandwidth_hz` 与 `low_hz/high_hz` 表达测得或请求的窗口，`analysis_bandwidth_hz` 是实际分析通带；AM/WFM 的 `center_hz` 可由载波／鉴频细化，不必等于测量窗口中点。
- `GET /api/sdr/scan/signals/{id}`：按需读取特征、协议证据、实际 IQ 来源及采样时间。时间为服务接收时的主机时间，不能当作已校准 RF UTC 时间。
- `GET /api/sdr/scan/events`：有界 SSE 变更通知，每个引擎最多 8 个订阅；通知合并为最新版本，不积压 IQ 或完整快照。浮窗可见时收到通知立即刷新，断线时恢复 500 毫秒轮询，隐藏时断开订阅。
- `POST /api/sdr/scan`：`start`、`pause`、`stop`、`configure`、`identify`、`identify_region`、`cancel_region`、`ignore`、`clear`。

所有命令使用当前 `service_id`、唯一 `request_id` 和十进制字符串 `capture_epoch`。除 `identify_region`/`cancel_region` 外，还要求 GET 返回的 `scan_id` 和 `expected_revision`。`identify`/`ignore` 额外要求 `signal_id`、字符串 `signal_generation`。成功回包带 `request_id` 与最新快照；同一 ID 和相同内容重试返回原回执，不同内容拒绝。冲突返回 409，错误字段为 `code`、`error`、`request_id`。

`identify_region` 示例（身份须从当前 GET 读取）：

```json
{"type":"identify_region","service_id":"…","request_id":"unique-id","capture_epoch":"…","low_hz":9830000,"high_hz":9840000,"origin":"waterfall"}
```

`origin` 为 `spectrum`、`waterfall` 或 `manual`，数据源始终为 `live_iq`。请求后收集新的连续观察块，最多分解 8 个区域；新选区替换临时组，不修改连续扫描范围或隐式启动扫描。越过有效采集边界会拒绝，不能静默裁剪或调谐。服务、采集几何、真实采集代次或参考电平改变会使旧结果失效；SDK 周期性幅度校准刷新只重装当前观察块并按比例更新本底，不取消识别；取消和新选区阻止迟到回包覆盖新状态。

`clear` 支持 `scope: "all" | "inactive"`，默认清除全部；保留连续扫描运行状态、范围、频道表和正式接收机。它同样检查身份／修订并去重，可在采集断开时清理旧结果。

`configure` 仅修改提供的字段：`range: {low_hz,high_hz} | null`、`channels: [{low_hz,high_hz}]`（最多 256）、`threshold_db`（5–20）、`auto_identify`。没有频道表时为区域发现。正式接收机创建可携带 `scan: {capture_epoch,signal_id,signal_generation}`，服务在预检及提交时复核推荐来源。

Fake 模式只有独立基带回放，没有共同的 RF 采集 IQ，因此不提供虚构扫描；扫描算法在单独合成测试中验证。实机准确率、长时间 RF 和高负载能力需按实际设备、速率及接收配置验收。

完成结果的 `timing` 包括 `queue_ms`、`sampling_ms`、`feature_queue_ms`、`processing_ms`、`total_ms`、`observation_seconds`、`checkpoints` 和 `early_exit`；均为主机单调时钟下的耗时，采样耗时包括检查点间的分析／预算等待，`total_ms` 从候选入队开始，不含发现阶段。`checkpoints` 表示最后观察阶段编号（1–3），不表示实际作业数。统计另含特征作业数、完成数、提前完成数、延长观察数和当前 CPU 预算等待时间。提前完成只缩短观察，不提升调制结论的置信等级或确认协议。

## 验证

`cargo test --release -j 1 --manifest-path backend/Cargo.toml --bin websad -- --test-threads=1` 与前端 Vitest 覆盖算法、命令、资源和选择状态。`tools/e2e/signal_scan.mjs` 和 `tools/bench-signal-scan.py` 需要显式设置 `WEBSA_SCAN_LIVE=1`，对已运行的实机服务执行浏览器闭环和 1/8/16 路测量；产物目录必须指定在仓库外。后者只在单信道基线上运行，创建带唯一标签的测试接收机，并在结束时清理测试录制和信道。

性能工具的 `--mixed-audio` 使用 AM／NFM／USB／LSB 混合接收，并逐路订阅全部 IQ 和音频，检查包序号、流身份及精确样本连续性；Current 为 WFM 时也检查解码事件流。默认仍使用附加 IQ 信道。两种模式均检查 Current 的 IQ／音频录制、满容量等待、已有 IQ 复用，以及正式创建抢占临时探针；录制检查遍历全部卷和索引分页，并复核块数、样本总数及跨块位置。

`tools/verify-broadcast-scan.py` 是针对现场 9–10 MHz AM 与 100–107 MHz 广播 FM 的可选回归，需 `WEBSA_SCAN_LIVE=1`、单 Current 基线和仓库外 `--artifacts`。它临时调谐并恢复采集，检查多路发现、实际调制／导频证据和各三次独立选区完成，并保存每个候选首次完成时间及首末结果延迟（50 毫秒轮询粒度，起点为命令返回后）；现场没有这些信号时应失败，不能作为通用 CI 或 RF 准确率结论。浏览器 gate 必须等到选区 `complete`，取消、失效或其他终态不能冒充识别完成。
