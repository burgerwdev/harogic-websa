# FT8 信噪比验收

基线和候选版本使用相同的确定性输入。基线身份记录在
`tools/bench/ft8_snr_validation_v2.json`。编译完成后串行计时，期间不运行其他构建或测试。

- 在抵消前的原始接收 IQ 上测量 S/(N0 × 2500 Hz)。数值为估计值，不静默裁剪或替换。
  −25…+10 dB 之外的有限值仍显示。
- 独立编码 GFSK 加实数／复数 AWGN：−30、−27、−24、−20、−10、0、+9、+15、+20 dB，
  采样率为 8／12／48 ksample/s。固定噪声实现中，≥−20 dB 时绝对误差 ≤1.5 dB，
  更弱时 ≤3 dB；−10 dB 的独立随机种子平均有符号误差绝对值 ≤0.5 dB。
- IQ 整体乘以 0.01／1／100 后有限估计变化 <0.01 dB；缩放本身不表示削波。
  衰落和非栅格频率沿用相同容差。小幅未消除频偏由回归诊断，解码器不得搜索已知消息来拟合频偏。
- 强邻频 CW、多个邻频编码信号及倾斜本底保留有限值；明确合成的可分离场景误差 ≤3 dB。
  检测到的污染／非平坦本底独立标记。同频干扰无法分离，不能将结果视为独立发射机功率。
- 接收边缘和不完整突发使用可用参考，保留可计算值并标记支持不足。符号确实不足、
  零噪声／信号、元数据无效和非有限 IQ 返回 null 及原因。比例仍有限时，削波为质量限制。
- JSON `snrDb` 等于 `measurement.value`，包括 null。质量、数值类型和原因保留到输入处理、
  历史及 JSONL／CSV 导出。数值旧 ABI 和现有 SDE2 封装保持兼容。双语说明降级及不可用状态，
  主题对比度使用现有主题变量。
- 保留解码回归及最低要求：相同 WSJT-X 输入 −20 dB、独立弱 GFSK 实际消息恢复、OSD、
  灵敏度、真实时隙和抵消。不产生无关解码；SNR 为 null 不得丢弃已解码文本。
- 运行十六 owner 隔离、阻塞搜索和满邮箱检查。不新增队列、worker、解码候选预算或采集配置。
- 分开报告相同输入的测量器和完整解码器 wall／CPU 中位数。测量器 wall／CPU 中位数
  ≤基线的 1.25 倍，完整解码器中位数 ≤1.10 倍，并保留现有计时 gate。
  这些是主机测量结果，不是硬实时期限。

统计标定与解码灵敏度分开验收。验证保留全部场景、完整输入范围及以上数值容差。
