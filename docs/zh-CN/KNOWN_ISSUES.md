# 已知限制与注意事项

1. **libhtraapi 偶发段错误/阻塞**: RTA 连续调用失败会先原地重配两次；仍失败或发生
   native 崩溃/调用超时时，supervisor 重启 worker；设备固件完全挂死时仍可能需重插拔。
   Web 与 SDK 的常驻进程隔离留待 VSA 架构阶段。
2. **SAStudio4 占用**: 设备单句柄, 官方软件运行时 Device_Open 返回 -1
3. **外部参考锁定**: 需正确设置 ExternalSystemClockFrequency=10MHz 且外部信号接入; 
   Ext 模式失锁自动回退内部(正常设备行为), 用 ExtForce 强制
4. **SystemClockSource=External 危险**: 设置会导致设备挂死(勿用)
5. **归一化**: 外部扫描源需覆盖测量带宽, 源驻留时间 ≥ 分析仪 hop 时间;
   CW 激励下仅有源点处归一化有效(基线钳 0)
6. **相噪**: 100Hz/10MHz 边界频偏不准; 最小输入 -50dBm
7. **点数**: 前端保峰重采样, 显示点数=设备原生(请求值仅影响设备配置)
8. **GNSS ppm**: RefClkFreqOffset 部分固件不填充(恒 0), 校准后可用计算值
9. **寻谷语义(频率方向)**: 左右寻谷按频率方向(与寻峰一致) — Valley 定位显示数据全局最低点,
   左/右跳到相邻凹陷(独立谷); 凹陷内多个局部极小已合并(25bin), 谷列表项与 Valley 定位一致
   (合并时重建为凹陷内 disp 全局最低), 跳回最深谷无偏差
10. **smooth 与寻峰寻谷**: smooth 开启时极点检测完全基于平滑曲线(与显示一致), 幅度用平滑值;
    关闭时用原始数据(Raw Anchor 原始邻域真实极值); 谷排序/去重: 峰 3bin、谷 25bin(凹陷合并)
11. **Pk 阈值**：值存于槽位，并且**每个测量几何只拟合一次**（span/RBW/Ref/dB per div/points/中心）；
    信号幅度单独变化不会再移动门限，峰值表与 marker 峰搜索也不会再随之重排。用户编辑后锁定直到
    再次点 Auto 按钮；所有 marker 关闭时不更新
12. **寻峰/寻谷定位取最近列表项(±3bin)**: 右移不会绕回自身（匹配到相邻 bin 曾使右移看起来卡住）
13. **手动衰减下的 Auto**：不再暂停。Auto Scale 是一次性动作，而保护性安全量程（IF 溢出、严重削顶）
    与 Atten 设置无关地始终运行（此前手动衰减会静默关闭过载保护，IF 溢出（-12）时画面会冻住）
14. **远程访问**: query token 可能进入浏览器历史/代理日志，远程控制应通过 HTTPS 反向代理
15. **快速退出**: worker 使用 `os._exit` 规避厂商 SDK 析构崩溃，因此退出时不会发送 WS close frame；浏览器会自动重连
16. **剩余硬件验证**: USB 热拔插、GNSS/1PPS 校准及 6/7/9 GHz 长时间压力测试仍需覆盖；
    频繁 SWP/RTA 切换、慢客户端与 60 s SDR 音频连续性已由 Playwright 状态回归覆盖（音频 worker 下 worklet underrun 为 0）。
17. **信道类测量的分辨率下限**: 信道功率/OBW/ACPR 基于显示迹线计算，因此受点数限制。
    当 RBW 远小于显示 bin 间隔时，CW 载波只占 1~2 个显示 bin，OBW 会停在该量级
    （实测 span 100 MHz / 998 点：RBW 100 kHz → OBW 401.6 kHz，RBW 10 kHz → 200.8 kHz）。
    需要更精细的 OBW 时请减小 span 或增大点数，而不是一味减小 RBW。
18. **RTA 触发电平的行为（实测）**: 电平触发按**门限穿越**（默认上升沿）动作——稳态信号若在启用触发时已高于门限，
    不会再有穿越，因此会一直等待（画面无新数据）；等待期间设备**不发送任何数据包**，所以画布会停在上一帧，
    应用因此采用"启用即清图 + 等待角标"的交互。`Intercept ≥ …`（POI）是当前配置**保证**能截获的最短突发时长。
    RTA 触发源中只有 `bus`（每帧由主机总线触发，约 100 fps，默认）可用；`freerun` 实测取不到数据，故未在界面提供。
    设备侧触发是 RTA 域能力：SWP 的触发源只有内部自由运行与外部触发，没有电平触发字段；普通模式界面上的电平触发改由前端软件实现，见下一条。
19. **普通模式的触发是软件实现的**: SWP 没有电平触发字段，界面上的电平触发由前端完成——按"相邻两次
    扫描之间是否发生门限穿越"判定（最小时间单位是一次扫描），等待触发期间画面保持实时、命中才定格。
    因此 RTA 的硬件时序项（防抖/延迟/预触发/采集时长/重触发/触发输出）与 POI 在普通模式下置灰不可用。
20. **SDR 采集中心与零中频伪影**: IQS 现在严格按用户设定中心采集（旧版会抬高 200 kHz 规避零中频 DC，
    副作用是显示窗最低 200 kHz 采不到、左侧留白，已移除）。因此 IQ 直流/本振泄漏伪影位于全景图中心；
    若信号正好在设定中心，会与该伪影重叠。
21. **SDR 音频链路**: 音频的接收与投递都由独立 worker 经单独的 `?audio=1` WebSocket 完成，并直接驱动
    AudioWorklet（显示连接用 `?noaudio=1`，不含音频）。因此残余的音频断续属于浏览器侧 worklet 环形缓冲
    underrun，而不是服务端丢帧；`document.getElementById('spectrum').dataset.sdrAudio` 暴露
    `enabled/muted/frames/buffered_ms/underruns/rms/worklet/worker` 便于排查。
22. **厂商 ADM（SINAD/SNR/THD）是单音指标**: 真实广播节目没有主导调制单音，厂商 `ADM_*` 数值会塌到 ~0，
    THD 无意义（同一段代码对 1 kHz 单音：SINAD ~7、SNR ~12）。SDR 面板已不再显示该行（`cur-sdr-adm` 已移除）；
    原始数值仍保留在 STATUS 的 `sdr.adm` 供 API 使用。
23. **SDR 静噪阈值是"信道功率 dBFS"**: 与解调模式/IF 带宽相关（带宽越大噪底越高），同一个数值在不同模式
    效果不同。门限带 3 dB 迟滞 + 0.3 s 保持 + 5/80 ms 平滑，所以不会在阈值附近抖动。
24. **IF AGC 保持关闭（`EnableIFAGC=0`）**：与官方 `Profile.xml` 一致；本机可用硬件无法让中频饱和，
    因此 AGC 无观测效果。接线与 `ifagc_gain` 回读保留作诊断用（`WEBSA_IFAGC=1` 可翻转默认值做 A/B）。
    一个值得记住的测量前提：**tinySA Ultra+ 输出上限约 −18.5 dBm**——早期"升到 0 dBm 读数钉住"被误判为
    接收机压缩，实际是源到上限；源在 −18.5 dBm 时 SAN-90 误差约 **−0.68 dB**，且 `preamp=AutoOn` 时
    器件自行保持 `preamp_actual=1`（拒绝旁路）。
25. **无需频率响应补偿**：校准数据已烧入固件，**不要**调用 `Devcie_SetFreqResponseCompensation` 加载外部文件。
    以已知源（tinySA，−18.5 dBm，atten 0，preamp off）实测基线：100 MHz 误差 −0.68 dB；−30 ~ −18.5 dBm
    区间误差 0.4~0.7 dB，衰减联动正确。验证宽频平坦度时注意 tinySA 自身平坦度（典型 ±2 dB）会混入结果。
26. **1.000/2.000 GHz 的整数族尖峰是设备内部杂散**：三个模式（SWP/RTA/SDR）都存在、频率精确为整数 GHz，
    且位于**输入衰减器之后**——衰减每加 10 dB，尖峰"表观"电平反而上升约 10~13 dB（外部 CW 源读数恒定），
    故属 IF/ADC/时钟路径的内部杂散，不是接收到的信号。SWP 只是因 RBW 而看不见（1.9 kHz 及以下才浮现）。
    软件无法消除；如需可向厂商反馈 1/2 GHz 及旋转谐波族。
27. **仍未解释（低优先）：FM 广播段的"atten 反向"现象。** 101.7 MHz、span 1 MHz、`preamp=AutoOn` 时，
    实际衰减 3→18 dB 增加，读数反而上升约 15 dB（−71.4 → −56.4 dBm）。CW 已知源复测不复现，
    推测为多载波复合功率导致前端过载；要查清需在强信号环境下用已知源做对照。
