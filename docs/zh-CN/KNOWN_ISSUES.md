# 已知限制

## 设备与 SDK

- **独占访问**：`libhtraapi` 要求独占设备。SAStudio4 占用设备时，`Device_Open` 返回 `-1`。专有 SDK 可能阻塞或崩溃；部署版本仍需在实际硬件上验收拔插恢复与停机行为。
- **采集恢复**：SDK 持续停滞时，以原始原因结束采集。恢复须创建新的采集 epoch，不能续接旧时间戳。队列积压时按有界背压等待，直到明确失败，不重新打开设备。厂商管理线程卡在 SDK 调用中时，保留该线程，拒绝调用 SDK finish 或重新打开设备。采集故障由全局错误流程处理。
- **外部参考**：接入 10 MHz 参考信号，并相应设置 `ExternalSystemClockFrequency`。`Ext` 失锁后回退内部参考；`ExtForce` 强制使用外部参考。不要设置 `SystemClockSource=External`，它可能导致设备挂死。
- **GNSS 校准**：部分固件的 `RefClkFreqOffset` 始终为零；校准后应使用计算得到的偏差。GNSS/1PPS 校准及 6/7/9 GHz 长时间运行验收仍待完成。
- **IF AGC**：默认 `EnableIFAGC=0`，与厂商配置一致。IF 饱和时的效果尚未完成验收。
- **出厂校准**：校准数据保存在固件中。不要通过 `Devcie_SetFreqResponseCompensation` 加载外部频响文件。
- **内部杂散**：包括 1.000 与 2.000 GHz 在内的整数 GHz 杂散会影响 SWP/RTA/SDR。增加输入衰减时，其表观电平可能升高；SWP 使用窄 RBW 时可能显现。解读迹线时需将其视为设备伪影。
- **迹线网格**：可用点数由设备原生网格决定，请求点数不能保证相应的显示分辨率。固件忽略 `SWP_Profile_TypeDef.TraceBinSize_Hz`，因此不支持固定频点间距。`SET_TRACEGRID.points_strategy` 接受 `speed` 与 `accuracy`。

## 测量与触发

- **归一化**：外部扫描源必须覆盖测量带宽，驻留时间不得短于分析仪的跳频时间。CW 源只能有效归一化自身频点，基线钳位为零。
- **相噪**：100 Hz 与 10 MHz 边界频偏处不准确，最低输入电平为 -50 dBm。
- **信道测量**：信道功率、OBW 与 ACPR 根据显示迹线计算，受频点间距限制。即使 RBW 更窄，窄带 CW 信号也可能只占一至两个频点。需要更细的 OBW 分辨率时，应减小跨度或增加可用点数。
- **RTA 电平触发**：触发要求穿越门限。启用时已高于门限的稳态信号可能一直等待。`bus` 是支持的 RTA 触发源。POI 表示当前配置保证能捕获的最短突发时长。厂商超时也可能表示通信超时，因此等待状态可能未知；有限捕获完成须由设备与帧证据确认。Fixture 输入不模拟硬件命中。
- **扫频模式电平触发**：SWP 没有设备电平触发字段。前端按相邻两次扫描检测门限穿越，最小时间单位为一次扫描。等待触发时显示保持实时，命中后定格。扫频模式不提供 RTA 时序控制与 POI。

## SDR

- **零中频伪影**：IQ 直流与本振泄漏位于请求的采集中心，恰好处于该频率的信号会与伪影重叠。
- **上边缘缺口**：采集网格可能无法覆盖整个显示窗口的高频端。未覆盖的频点保留为缺口；RTA/SDR 不使用扫频模式的 GapFill 插值填补这些缺口。
- **厂商 ADM**：SINAD/SNR/THD 要求存在占主导地位的调制单音，不能有效衡量普通广播音频的质量；原始数值仍可从 STATUS 的 `sdr.adm` 获取。
- **静噪电平**：AGC 前调谐点的频谱峰值不是积分信道功率。调制会将功率分散到多个频点，因此应按接收信号和模式设置静噪门限。

## 接收与浏览器边界

- **接收容量**：后端支持三个独立配置的槽位。产品界面仅开放主槽位，进入 SDR 时会禁用辅助槽位。混音、录音与动态频道数尚未交付；内部 PFB bin 数不代表产品接收频道容量。
- **原始 DSP 输入**：直接调用 `Pipeline` 或 `AnalogDemod` trait 时，须提供有限输入。生产 `Receiver` 和离线入口会检查非有限值，原始 DSP API 不检查。
- **RDS**：解码文本质量仍有限；立体声指示表示导频存在，不表示左右声道节目内容不同。
- **AM**：调制度表示等效单音 RMS 包络深度，不是任意节目的峰值调制度。过调制会使绝对值包络折叠，可能低估有符号调制深度；结果不限制在 100% 以内。载波衰落会使频偏、调制度失效并清除锁定。恢复估计器限于 `min(IF 带宽 * 0.2, 接收器 IQ 采样率 * 0.1, 3000 Hz)`，接近边界时不判定锁定；该捕获范围上限不保证一定能锁定。同步检波开启不等于载波已锁定，这些指标也不构成真实射频接收质量验证。
- **FT8**：解码仅支持搜索窗口内的标准消息类型 1/2，不支持任意消息类型或无限制搜索。
- **SSTV**：不支持图像结束后的 FSK 呼号解码。
- **无线电传真**：支持自动 IOC 288/576 及 60/90/120/240 LPM；180 LPM 仅手动。每段最多 2400 行，达到上限后继续下一段。接收修复后，真实中途 IQ 样本循环回放 64.058 秒输出 127 行，7.7931 MHz 新采集的 8.045 秒样本输出 16 行；两者均使用未锁定的 IOC576/120 LPM fallback。录制事件回放还验证了浏览器 1810×127 图像显示与 PNG 导出。本次实时检查处于搜索状态，没有图像行。完整 APT/定相捕获、其他 IOC/LPM 组合、长图时钟漂移、频偏及衰落互操作仍未验收。
- **DRM**：短片段或循环编解码播放可能发生缓冲欠载；这类片段不能证明持续播放的连续性。编解码音频不经过接收器的 AGC、降噪、静噪与去加重，这些控件在界面中禁用；音量与音频启用仍可使用。NR 偏好保留，但实际 NR 为 Off。信令重配置及下一复用配置的生效时序尚未完整实现。
- **浏览器渲染**：20 fps 的采集目标不保证所有显示层都达到 20 fps。已有记录中，频谱、密度、瀑布与导航全部启用时约为 15 fps；本次未新增硬件或浏览器测量。

设备约束与探测背景见 [SDR 探测记录](../../tools/sdr_probe/FINDINGS.md)。其中硬件观察仅适用于相应配置，本文不构成部署版本的硬件验收。
