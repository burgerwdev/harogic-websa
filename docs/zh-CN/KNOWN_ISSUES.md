# 已知限制

## 设备与 SDK

- **独占访问**：`libhtraapi` 要求独占设备。SAStudio4 占用设备时，`Device_Open` 返回 `-1`。专有 SDK 可能阻塞或崩溃；部署版本仍需在实际硬件上验收拔插恢复与停机行为。
- **采集恢复**：SDK 持续停滞时，以原始原因结束采集。恢复须创建新的采集 epoch，不能续接旧时间戳。队列积压时按有界背压等待，直到明确失败，不重新打开设备。厂商管理线程卡在 SDK 调用中时，保留该线程，拒绝调用 SDK finish 或重新打开设备。采集故障由全局错误流程处理。
- **外部参考**：接入 10 MHz 参考信号，并相应设置 `ExternalSystemClockFrequency`。`Ext` 失锁后回退内部参考；`ExtForce` 强制使用外部参考。不要设置 `SystemClockSource=External`，它可能导致设备挂死。
- **GNSS 校准**：部分固件的 `RefClkFreqOffset` 始终为零；校准后应使用计算得到的偏差。GNSS/1PPS 校准及 6/7/9 GHz 长时间运行验收仍待完成。
- **IF AGC**：默认 `EnableIFAGC=0`，与厂商配置一致。IF 饱和时的效果尚未完成验收。
- **出厂校准**：校准数据保存在固件中。不要通过 `Devcie_SetFreqResponseCompensation` 加载外部频响文件。
- **内部杂散**：包括 1.000 与 2.000 GHz 在内的整数 GHz 杂散会影响 SWP/RTA/SDR。增加输入衰减时，其表观电平可能升高；SWP 使用窄 RBW 时可能显现。解读迹线时需将其视为设备伪影。
- **迹线网格**：可用点数由设备原生网格决定，请求点数不能保证相应的显示分辨率。固件忽略 `SWP_Profile_TypeDef.TraceBinSize_Hz`，因此不支持固定频点间距。`SET_TRACEGRID.points_strategy` 接受 `speed` 与 `accuracy`。

## 测量与触发

- **归一化**：外部扫描源必须覆盖测量带宽，驻留时间不得短于分析仪的跳频时间。CW 源只能有效归一化自身频点，基线钳位为零。
- **相噪**：100 Hz 与 10 MHz 边界频偏处不准确，最低输入电平为 -50 dBm。
- **信道测量**：信道功率、OBW 与 ACPR 根据显示迹线计算，受频点间距限制。即使 RBW 更窄，窄带 CW 信号也可能只占一至两个频点。需要更细的 OBW 分辨率时，应减小跨度或增加可用点数。
- **RTA 电平触发**：触发要求穿越门限。启用时已高于门限的稳态信号可能一直等待。`bus` 是支持的 RTA 触发源。POI 表示当前配置保证能捕获的最短突发时长。厂商超时也可能表示通信超时，因此等待状态可能未知；有限捕获完成须由设备与帧证据确认。Fixture 输入不模拟硬件命中。
- **扫频模式电平触发**：SWP 没有设备电平触发字段。前端按相邻两次扫描检测门限穿越，最小时间单位为一次扫描。等待触发时显示保持实时，命中后定格。扫频模式不提供 RTA 时序控制与 POI。

## SDR

- **零中频伪影**：IQ 直流与本振泄漏位于请求的采集中心，恰好处于该频率的信号会与伪影重叠。
- **上边缘缺口**：采集网格可能无法覆盖整个显示窗口的高频端。未覆盖的频点保留为缺口；RTA/SDR 不使用扫频模式的 GapFill 插值填补这些缺口。
- **厂商 ADM**：SINAD/SNR/THD 要求存在占主导地位的调制单音，不能有效衡量普通广播音频的质量；原始数值仍可从 STATUS 的 `sdr.adm` 获取。
- **静噪电平**：AGC 前调谐点的频谱峰值不是积分信道功率。调制会将功率分散到多个频点，因此应按接收信号和模式设置静噪门限。

## 接收与浏览器边界

- **接收容量**：十六个独立定义共用一个采集窗口；停用仍占定义名额，删除释放名额。每路完整通带及过渡带须位于共享采集内。普通窄带覆盖原有采集档位，包含每相十六抽头、每秒六千二百五十万个输入样本的五十兆赫可用窗口。宽带模式、搜索、神经降噪与外部解码不再受预测CPU/输出量或算法数量准入限制。实际持续能力取决于宿主和输入；有界逐路队列仅失败受影响处理分支，独立IQ可继续并支持显式重试。原生崩溃、共享源故障及整机CPU饱和仍有更大影响范围。工作台支持选台、本地混听及全服务十六个录制任务。粗频率箱数与长期容量目标不表示当前接收路数。十六路持续射频验证尚待完成。早期八路逐路隔离版本在受测宿主上通过 50 MHz／62.5 MSps／每相16抽头下普通射频三十分钟、混合射频十一分钟及超过十分钟八任务录制；检查了已知音调、FT8结果、网络PCM/IQ连续性、独立归档读取及真实RF浏览器操作。这不表示物理扬声器听音或任意重模型组合的持续能力。
- **全带宽主机负载**：早期运行发生USB交接溢出；同输入分层测试在自建有限CPU脉冲下也复现了旧版溢出。PFB池现允许每个现有工作线程各执行一个作业，消除四线程却在三个在途作业时提前等待的问题。上述持续RF检查在不修改无关进程、USB队列容量、采集带宽或滤波质量的条件下通过。短暂积压仍会发生，整机饱和、vendor停顿及共享采集故障仍是明确边界；这些测量不保证任意宿主负载下都不中断。
- **原始 DSP 输入**：直接调用 `Pipeline` 或 `AnalogDemod` trait 时，须提供有限输入。生产 `Receiver` 和离线入口会检查非有限值，原始 DSP API 不检查。
- **RDS**：解码文本质量仍有限；立体声指示表示导频存在，不表示左右声道节目内容不同。
- **AM**：调制度表示等效单音 RMS 包络深度，不是任意节目的峰值调制度。过调制会使绝对值包络折叠，可能低估有符号调制深度；结果不限制在 100% 以内。载波衰落会使频偏、调制度失效并清除锁定。恢复估计器限于 `min(IF 带宽 * 0.2, 接收器 IQ 采样率 * 0.1, 3000 Hz)`，接近边界时不判定锁定；该捕获范围上限不保证一定能锁定。同步检波开启不等于载波已锁定，这些指标也不构成真实射频接收质量验证。
- **FT8**：解码仅支持搜索窗口内的标准消息类型 1/2，不支持任意消息类型或无限制搜索。
- **SSTV**：频偏从每个有效 VIS 头估计，图像接收期间不持续跟踪。内部通带固定为 300–2700 Hz。不支持图像结束后的 FSK 呼号解码。
- **无线电传真**：支持自动 IOC 288/576 及 60/90/120/240 LPM；180 LPM 仅手动。每个存储段最多 2400 行。真实中途录音已验证未锁定的 IOC576/120 LPM fallback。435 MHz 的 Pluto→SAN-90 实机射频测试还收到完整的 1810×64（IOC576/120 LPM）和 905×256（IOC288/240 LPM）页面，均恢复定相时钟、确认 APT 停止，且无缺失行。这些台架结果不代表其他行频/调制组合、长图漂移、频偏或衰落互操作已验收。
- **传真留存**：历史只在当前浏览器会话内保留，每频道 Gray8 实际分配上限为 20 MiB。当前页和查看中的页受保护；预算不足时停止继续留存并显示状态。先保存需要的页面，再删除页面释放空间；已停止留存的 transmission 不会回补。后端快照也有上限，长页较早的存储段可能不再可用。整页 PNG 每边最多 32767 像素、总计最多 16777216 像素；超限或缺少前段时须分段导出。接收日期表示浏览器首次收到图像行的时刻，不代表台站发送或图上有效时间。
- **DRM**：短片段或循环编解码播放可能发生缓冲欠载；这类片段不能证明持续播放的连续性。编解码音频不经过接收器的 AGC、降噪、静噪与去加重，这些控件在界面中禁用；音量与音频启用仍可使用。NR 偏好保留，但实际 NR 为 Off。信令重配置及下一复用配置的生效时序尚未完整实现。
- **外部解码器**：依赖可用不等于信号锁定或射频互操作通过。multimon-ng 与 rtl_433 要求精确输入格式，设备协议由安装版本决定。OnAir Web 集成覆盖 AIS/APRS/FT4/WSPR/Meteor/ADS-B，RTTY 使用单独构建的 OnAir 伴随程序；并非完整桌面目录、数字语音 codec 或电视媒体输出。宽速率模式经原始 IQ 直接分支，仍须符合采集带宽与过渡带几何；实际过载由受影响分支报告。整数抽取发布真实率，接收适配器转换到 GPS 的 4 MSps 或 ADS-B 的 2 MSps。该路径本身不证明实机接收通过，也不提供 DAB/电视解码器。
- **OnAir 输入与时序**：IQ 经私有 loopback 源以固定缩放 8-bit 传输。AIS 要求固定双信道中心 162 MHz；其他上游频段约束继续生效。FT4/WSPR 要求与 UTC 对齐的实时输入，无时间对齐信息的录音/循环 fixture 回放被拒绝。EOF 仅有界排空，上游不提供完成确认。Meteor 当前发送部分图像条带，没有整图结束指示。
- **外部验证范围**：Acurite IQ 录音与 POCSAG 鉴频音频录音实际驱动 rtl_433/multimon 解码，并验证接收器采样率适配；AIS/APRS/Meteor 合成 IQ 验证结构化输出，与 UTC 对齐的干净合成输入经真实 Receiver 和 OnAir 桥接解出 FT4/WSPR 消息。这些检查证明相应路径可用，不代表射频灵敏度、衰落表现或所有 multimon 模块逐项验收。
- **频移射频台架验证**：Pluto→SAN-90 在 435 MHz 台架中心、Pluto gain −30 dB 下实际解出 DTMF `123A#`、APRS `N0CALL-1` 与 `WEBSA APRS TEST`、AIS MMSI `367000001` 及预期位置、FT4 `CQ K1ABC FN42`、WSPR `K1ABC FN42 30`。每次首条匹配结果到达即停止发射，未报告接收器错误。合成信号验证了这些实机路径，不代表被动空中接收或经标定的灵敏度。
- **ADS-B 与 RTTY 离线验证**：4000 万个已知 ADS-B IQ 样本以 4 MSps 进入生产 Receiver 并适配为 OnAir 的 2 MSps 输入，全部 270 帧解码成功，得到 ICAO `40621D`、呼号 `EZY123`、高度 38000 ft 及经独立 CPR 计算核对的坐标。45.45 baud/170 Hz 的正常与反向 RTTY fixture 经生产 Receiver 解出完整已知文本、数字和标点，帧错误为零。这些结果属于合成 IQ 验证。
- **RTTY 射频验证**：正常与反向模式均经既有 USB WAV 发射器，在 435 MHz Pluto/SAN-90 台架、gain −30 dB 下解出 `CQ CQ DE WEBSA TEST 0123456789 1/2 -.:? THE QUICK BROWN FOX`。两次均在 31 秒内完成，匹配文本到达即停止，未报告接收器错误。
- **GPS L1 C/A**：可选原生桥接把精确 4 MSps 的 SDR IQ 交给独立 GNSS-SDR，正常接收中心为 1575.420 MHz，不读取 SDK 内建 GNSS 状态。显式设置 `WEBSA_GPS_BENCH_HZ` 可启用一个精确匹配的 400–450 MHz 频移台架接收频率，结果单独标记；该设置不配置发射器。卫星跟踪/导航与定位有效性分别展示，过期定位失效，启动状态明确为未定位。依赖安装成功本身不能证明天空接收或录音解码通过。FIFO 没有输入完成确认，结束时有界排空并报告上游完成未知。频移合成信号的台架接收不能证明被动 GPS 天空接收；不提供 GPS L1 频段发射。
- **GPS 真实录音验证**：CTTC 2013-04-04 完整录音已通过生产 Receiver，以 4 MSps 转发全部 4 亿个复数样本，监测报文格式错误为零，跟踪 5 个 PRN，解码 67 个导航子帧并输出 232 个有效 PVT 快照。最后有效位置为 41.2748489°、1.98766735°，高度 78.13 m，GPS 周为 1734。此结果证明真实录音解码；被动天空接收及频移台架射频效果仍须分别验证。
- **GPS 合成信号验证**：60 秒按样本计时的 2.6 MSps 场景，经生产 Receiver 适配为 4 MSps 后由 GNSS-SDR 解出 77 个有效 PVT 快照、7 颗定位卫星及 11 个 PRN 的 77 个导航子帧，监测报文格式错误为零。相对设定的北纬 25.2°、东经 55.36°，最后水平误差 0.54 m。此结果属于离线合成输入，不代表射频接收。
- **GPS 频移射频验证**：SAN-90 从冷启动建立 3.90625 MSps 采集，在 435 MHz 接收 gain −30 dB 的 Pluto 合成场景，63.41 秒内得到 4 颗卫星参与的有效定位，相对设定位置水平误差 3.65 m，未发生接收器错误。首个匹配定位到达即停止发射并恢复 Pluto 参考时钟。此结果验证频移台架路径，不代表被动天空接收。
- **通用 Decode 留存**：提供者结果仅在浏览器会话内保存，每频道最多 200 条结果 / 8 MiB（含条带解码像素内存），每图最多 512 个条带。淘汰可见；晚订阅者不获得 WebSA 通用结果历史快照。通用图像当前没有 PNG 导出动作，原生 SSTV/传真继续使用各自留存和导出契约。弹窗共享主窗口会话，并随主窗口关闭。
- **浏览器渲染**：20 fps 的采集目标不保证所有显示层都达到 20 fps。已有记录中，频谱、密度、瀑布与导航全部启用时约为 15 fps；本次未新增硬件或浏览器测量。

设备约束与探测背景见 [SDR 探测记录](../../tools/sdr_probe/FINDINGS.md)。其中硬件观察仅适用于相应配置，本文不构成部署版本的硬件验收。
