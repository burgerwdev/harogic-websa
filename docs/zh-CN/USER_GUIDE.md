# 接收操作

[文档目录](INDEX.md)

## 频谱与采集

SWP 用于扫描测量，RTA 用于实时频谱／密度，SDR 增加原生接收、音频及解码。
中心频率和跨度配置采集；显示缩放、Top／Bottom 改变视图。显示放大不能提高已采集数据的分辨率。
参考电平、衰减和前置放大配置硬件量程；自动缩放是一次性操作。

SDR 中，中心频率同时移动共享采集中心和 Current；IQ 带宽只改变共享采集，保留各路调谐。
“移到中心”将采集移至所选信道。移动共享采集可能中断全部信道并创建新的录制片段。

## 信道与监听

“信道”打开共享工作台。Current 固定占一路，另可保存最多十五条信道，共享一个采集源。
已保存信道无论带内、带外或主动停用都占名额，只有删除才释放；关闭窗口、停止监听和隐藏卡片均不释放。
完整通带及过渡带位于实际采集范围内时接收。选择模式、频率后检查预览并应用。
关闭窗口不会停止信道接收或录制。

“工作台”旁的网格按钮打开唯一的全部信道概览；任一信道窗口的“概览”按钮可将该窗口转为概览，
原概览窗口恢复其编辑视图。卡片显示频率、模式、带宽、创建时间和实时电平，监听采用图标按钮。
可按创建时间、频率、名称、类型或活动状态排序；箭头切换时间、频率、名称和类型的升降序，中文名称按拼音排序。
计数表示已建信道数／服务容量，包含独立窗口中的信道。点击卡片名称可直接改名，回车或离开输入框保存，Esc 取消。
与主频谱选中频率一致的卡片显示准星及高亮边框，与工作台的编辑选择互相独立。

布局支持自动网格、1～8 列和自由摆放。拖动时的占位框预览松手后的落点，聚焦卡片后也可用 Alt＋方向键移动；
自由布局开启吸附后，拖动期间显示卡片大小的网格，落点预览吸附到最近的空格位；开启吸附时已有卡片也会对齐。
关闭吸附后不显示网格，卡片可按像素自由放置。“适配”按卡片布局调整窗口，超出范围时滚动查看，不压缩操作按钮。
双击卡片或使用独立窗口按钮可将信道取出；独立信道的 dock 将其放回概览，“收回全部”收回所有独立信道窗口。
概览本身仍可弹出为独立浏览器窗口，并移回页面。

可见卡片以每秒十帧显示现有播放 PCM 的波形，测量点在本地监听音量之前；波形归一化以便观察，dBFS 电平保持绝对标度。
未监听信道保留状态文字，解码文字保留滚动显示。复用同一播放路由的信道共享其波形和电平读数，隐藏卡片释放自己的波形引用；打开概览不会新增音频订阅。

Current 是固定的临时调谐通道，主界面始终调整它；工作台选中、编辑或监听其他信道都不会改变 Current。
概览和管理台采用相同规则：没有已保存的同频信道时，将 Current 固定显示在第一格／首行；存在同频信道时隐藏 Current 条目，高亮所有同频信道并显示准星。
隐藏只合并显示，不改变实际接收、监听或容量；编辑选中状态与频率高亮分别表示。Current 名称固定，可保存或停止，不能删除。
主界面加号将 Current 保存为独立信道，后续调谐不会改变副本；再次保存相同配置时定位已有副本。同频但模式、带宽或处理设置不同可独立添加。
需要另一条完全相同的信道时使用“复制信道”。已有重复信道仍独立保留，需显式删除；相同音频继续由监听层避免重复播放。

改变采集中心或 IQ 带宽后，已启用但未被完整覆盖的信道保留所有设置，显示“带外 · 等待覆盖”，覆盖后自动恢复原来的接收及监听；用户主动停用的信道保持停用。
仅缩放或平移显示画面不影响接收，覆盖判断只使用实际采集范围。概览和管理台默认保留带外信道，并提供当前频段筛选；暂停时停止刷新波形和电平，保留历史解码文字。
同频高亮与接收状态独立，同一信道可同时高亮并显示带外。

主面板始终调谐 Current；工作台编辑选择只作用于该视图。
监听音量、声像、静音和独听控制本地扬声器。后端增益、AGC、静噪及降噪会改变共享 PCM，
也会影响已发布音频的录制。停止或失败的信道不能监听。

模拟解调的控制区提供 12、24、48 kHz 音频采样率快选，默认 48 kHz；Preset 恢复此默认值。
按钮只修改当前信道的采样率，外部设置的其他采样率仍显示实际值。模式专用设置继续在解码窗中操作。

双击折叠条频道名可改名；回车提交，Escape 或离开输入框取消。名称获得焦点后也可按 F2／Enter 编辑。播放电平从音频输出实际消费的样本计算 RMS 和样本峰值，采用固定 −60…0 dBFS 标度、快起慢落及一秒峰值保持；测量点在本地监听增益／声像／主音量之前。静音、暂停或播放数据过期会清零；未监听时的解调遥测明确标为未播放。

RF 测量 `level_dbfs` 是音频处理前的归一化复数 IQ 功率；`channel_dbm` 是调谐 FFT bin 峰值。
两者都不代表解调后的声音大小。音频表应读取播放 PCM 并明确采用 dBFS 标度；数字样本峰值表
不是校准射频功率计、真峰值表或广播响度合规测量表。

## 解码与预设

通过模式目录的可用性和原因判断是否缺少外部 provider。可选 provider 按[工具指南](../../tools/README.md)
独立安装。“可用”表示依赖已就绪，不表示收到或锁定信号。解码窗可折叠或弹出，仍共享同一接收会话。

命名预设保存已确认的信道处理及基带设置。载入时先预览，再应用到现有信道，保留身份和本地监听。
它不恢复整组场景，也不恢复录制任务。会话内的模式记忆只恢复编辑候选，仍须确认应用。

## 录制与回放

选择 IQ、已发布音频或解码结果。它们共享全服务十六个任务名额；同一路录制多种类型会占多个名额。
关闭浏览器后任务继续。带外暂停会结束当前片段、进入等待；覆盖恢复后在同一任务中写入新片段，保留中断起止时间。
用户停止录制后不会因重新覆盖而自动恢复；设备或处理故障等异常中断仍保留原有的失败处理。停止后须等待收尾完成，再试听、导出、改名或删除。

新音频录制默认 Opus。WAV 保留已发布 Float32 PCM；FLAC 保存量化后的 24 位 PCM；Opus 有损。
任务开始时确定格式，途中不切换。浏览器监听音量／声像／静音／独听不进入录制。
文件试听独立于实时监听。

录制库支持名称／频率筛选、片段查看、下载和已结束任务管理。源变化及间隙保留为独立片段。
范围试听及离线 AM／USB／LSB／NFM 解调有容量限制，不是整份长归档的连续播放。
具体格式和限制见[录制参考](reference/RECORDINGS.md)，解码历史保留及验证范围见[已知限制](OPERATIONS.md)。
