# 运行排障与当前限制

[文档目录](INDEX.md) · [快速开始](GETTING_STARTED.md)

## 服务与设备恢复

先运行 `./status.sh`，查看所属进程、实际地址、日志位置、设备状态，以及运行程序是否与磁盘文件一致。
重建后若提示二进制已更换，应重启目标实例。使用命名实例时，各命令保持相同的 `--instance NAME`。
根目录启动器默认使用 8080 端口；直接运行 `websad` 默认使用 8099，且未指定 SDK 适配器时采用模拟输入。
启动配置见[快速开始](GETTING_STARTED.md)。

| 现象 | 检查与处理 |
|---|---|
| 设备打开失败或返回 `-1` | 关闭 SAStudio4 和其他 SDK 客户端；设备需要独占访问。 |
| 服务未运行 | 阅读启动器给出的日志，检查程序、前端和 SDK 依赖后，再执行 `./run.sh`。 |
| USB／SDK 采集停滞 | 检查原始错误和日志；先停止实例，再重新插拔 USB 并启动。永不返回的厂商调用可能阻止安全重开，必要时需重启主机。 |
| 接收处理失败但频谱仍更新 | 查看该接收机诊断并显式重试模式；`receiver_retiring` 表示旧线程／订阅尚未退出，稍后重试。 |
| 浏览器有界面但无声 | 启用浏览器音频，检查接收状态、监听／静音／独听、本地音量、静噪与解码锁定；DRM 还需支持的音频服务。 |
| 谐波／相噪模式拒绝配置 | 先停止测量，再修改 SWP 所属的频率、带宽、增益或时钟设置。 |

启动器不会监督或自动重启进程。共享采集失败影响依赖它的接收机；独立处理失败时，原始 IQ 和频谱可能
仍然可用。恢复成功后建立新的流身份，不把间隙两侧样本拼成连续数据。SDK 调用由常驻设备所有者串行执行；
阻塞调用结束前不能关闭或重开其句柄。具体规则见[状态归属](reference/STATE.md)。

频谱诊断区保留错误，直到匹配的成功操作或显式恢复将其清除。WebSocket 重连或其他命令成功不代表原故障
已恢复。报告问题时附上错误、当前模式、设备／SDK 版本和实例日志。

全速 IQS 的 `USB handoff full` 表示交接队列已满；`USB transfer failed` 则报告原始 USB 状态和已收到字节数。
错误附近的有界时间记录用于区分这些路径。回调时间是用户态处理时间，不是设备完成时间；
交接队列年龄也不是 USB 线程调度延迟，不能只凭其中一个数值判断故障原因。

## 射频电平、时钟与固件

- IF 溢出表示测量可能饱和。提高硬件参考电平或执行显式 Auto Scale。普通手动操作不会自动修改增益或参考；
  Auto 使用新采集数据，并有恢复次数／时间上限。显示视窗与硬件参考范围不同，显示仍像削顶时应对照实际回读。
- 音频 AGC、射频前端增益和静噪相互独立。静噪读取 AGC 前调谐 bin 的峰值，不是积分信道功率；最左侧
  −160 dBm 关闭静噪。各解调模式默认关闭静噪，Preset 也恢复为关闭。解码 RMS、RF IQ 功率和播放电平是不同测量，见[用户指南](USER_GUIDE.md)。
- 零中频 DC／本振泄漏位于采集中心。整数 GHz 附近的内部杂散也会出现在 SWP／RTA／SDR，其表观电平可能
  随衰减增大而升高。判断中心频率特征是否来自外部信号前，可移动采集中心观察。
- SAN-90 外部参考输入为 10 MHz。`Ext` 失锁后回退内部参考；`ExtForce` 要求有效外部参考。另一个厂商设置
  `SystemClockSource=External` 未在界面开放，可能使设备挂起。时钟及参考输出能力因型号而异。
- GNSS 1PPS 校准要求实际锁定的物理输入，否则厂商调用可能阻塞。固件 `RefClkFreqOffset` 为零不能证明准确。
  GNSS／1PPS 校准和高频段长时验收尚未完成，IF AGC 在饱和条件下的效果也未验收。
- 出厂频响校准保存在固件中，不要通过厂商 `Devcie_SetFreqResponseCompensation` 调用加载外部补偿文件。

## 测量与触发限制

| 项目 | 当前边界 |
|---|---|
| 迹线分辨率 | 点间隔由 SDK 原生采样点决定。不支持固定 `TraceBinSize_Hz`，可选择速度／精度策略；显示缩放不提高测量分辨率。 |
| 信道功率、OBW、ACPR | 使用所选显示绝对迹线，受其 bin 间隔限制。窄信号可减小跨度或增加可用点数；归一化迹线不提供绝对测量和绝对 CSV 导出。 |
| 归一化 | 外部扫频源须覆盖测量带宽，驻留至少一个分析仪跳频周期；CW 主要只能有效归一化其自身频率。 |
| 相噪 | 100 Hz 和 10 MHz 偏移边界不准确，最低输入约 −50 dBm；可用最大偏移两倍的扫频跨度交叉检查。 |
| RTA 电平触发 | 需要阈值穿越，布防前已高于阈值的稳定信号可能一直等待。支持 bus 触发源；超时不能单独证明等待或完成，模拟输入不模拟硬件命中。 |
| SWP 电平触发 | 浏览器比较连续两次扫描，最小时间单位为一次扫描；不适用 RTA 的延时、防抖、预触发和 POI。 |

Free Run 或 Escape 解除已确认的触发保持；Auto Scale 不解除布防。采集上边缘未覆盖的 bin 保持空白，
RTA／SDR 不使用 SWP GapFill 补齐。厂商 ADM 的 SINAD／SNR／THD 要求主导调制单音，不能作为普通广播
节目音频的通用质量指标。

## 接收机与解码器限制

服务最多允许十六个接收机定义和十六个录制任务。停用的接收机仍占定义名额，完整通带及过渡带必须位于共享
采集范围内。十六路持续真实 RF 验收尚未完成。CPU 饱和、SDK 停滞和共享源故障均可能中断接收，配置容量
不等于持续吞吐保证。

| 模式 | 当前边界 |
|---|---|
| AM | 调制度是单音等效 RMS 包络深度。过调制会折叠包络并低估带符号深度；载波衰落使指标无效，开启同步检波不代表锁定。恢复范围为 `min(IF 带宽 × 0.2, IQ 采样率 × 0.1, 3000 Hz)`。 |
| WFM／RDS | RDS 文本质量有限；立体声指示代表导频检测，不能证明左右节目内容不同。 |
| FT8 | 支持搜索窗口内的标准类型 1／2，不支持全部消息类型或无限制搜索。 |
| SSTV | 频偏来自有效 VIS 头，图像内不持续跟踪。内部通带固定为 300–2700 Hz，不支持图后 FSK 呼号。 |
| Radiofax | 自动支持 IOC 288／576 及 60／90／120／240 LPM，180 LPM 需手动指定。每段最多 2400 行，其他组合、长页漂移、频偏和衰落仍需专项验收。 |
| DRM | 短片段／循环播放可能欠载。编解码音频绕过 AGC、NR、静噪和去加重，音量与启用仍可用；完整信令重配置及下一复用时序尚未完整应用。 |

外部 provider 有各自输入要求和支持目录，安装成功不代表信号锁定。OnAir 集成覆盖 AIS／APRS／FT4／WSPR／
Meteor／ADS-B，RTTY 使用独立 companion；不包含完整桌面目录、数字语音和电视输出。其私有本地输入为
固定尺度的 8 位 IQ，AIS 要求固定信道对的 162 MHz 中心。FT4／WSPR 要求 UTC 对齐的实时输入，拒绝未对齐
回放。EOF 只能有界排空，没有上游完成确认；Meteor 输出部分图像条带，没有整图结束信号。

可选 GNSS-SDR 桥接使用精确 4 MSps IQ，通常工作于 1575.420 MHz，与 SDK 内置 GNSS 状态无关。
`WEBSA_GPS_BENCH_HZ` 允许一个明确指定的 400–450 MHz 平移接收频率，不配置发射。跟踪、导航和有效 PVT
是独立状态，过期定位失效，FIFO 的 EOF 完成状态仍未知。平移或合成接收不能证明被动天空接收。
采样率及结果字段详见 [provider 安装](../../tools/README.md)和[接口参考](reference/API.md)。

## 浏览器保留范围与问题报告

Radiofax 历史仅属于当前浏览器会话，每信道最多保留 20 MiB 已分配 Gray8。当前页和正在查看的页受保护，
占满预算后停止保留并显示提示。先保存再删除页面释放空间；停止期间内容不补录。后端快照也可能省略旧片段。
整页 PNG 导出每边最多 32767 像素、总计最多 16777216 像素；更大或不完整页面须分段导出。接收日期是首行
到达浏览器的时间，不是电台发射时间或图表有效期。

通用 provider 历史每信道最多 200 条／8 MiB（包含解码图像条带），每图最多 512 条带。淘汰会明确显示，
晚订阅者没有历史快照，通用图片暂无 PNG 导出；原生 SSTV／Radiofax 另有契约。弹出窗共享主窗口会话，
随主窗口关闭。采集帧率不保证浏览器绘制帧率，显示开销取决于保留数据、图层和主机。

直接使用 `Pipeline`／`AnalogDemod` 的调用者必须提供有限值；生产 `Receiver` 和离线入口会检查。
可复现问题报告及新的硬件／性能证据应遵循[开发指南](DEVELOPMENT.md)。旧运行结果通过 Git 历史追溯，
不代表当前构建已验收。
