# 模式、参数与状态所有权

## 参数所有权

`backend/` Rust 服务管理设备配置与采集状态；浏览器管理显示设置、编辑器与播放状态。

| 设置 | SWP | RTA | SDR |
|---|---|---|---|
| 中心频率 / 带宽 | 独立扫频中心 / 跨度 | 独立采集中心 / 跨度 | 采集中心 / 抽取率及接收机收听频率 |
| 参考电平 | SWP SDK 参考与本地显示窗口 | RTA SDK 参考与本地显示窗口 | 由 `SET_REF` 显式设置 IQS 参考；浏览器显示参考独立 |
| RBW / VBW / 扫描 | SWP 请求与实际值 | RTA 请求与实际值 | 采集与接收机速率计划 |
| 点数 / FFT 窗 / 杂散抑制 | SWP 专用 | 不适用 | 不适用 |
| 衰减 / 前置放大 / IF 增益 / 增益策略 | 共享 RF 前端 | 共享 RF 前端 | 共享 RF 前端 |
| 参考时钟 / 时钟输出 | 设备级 | 设备级 | 设备级 |

SWP 与 RTA 分别保存各自的请求参数，切换模式时互不覆盖。显示平均深度也分别保存（`avgTarget` / `avgTargetRta`）：有限 N 使用指数平均，α = 2/(N+1)；无穷使用累计均值。

## 默认值与预设

| 设置 | SWP 启动值 | RTA 启动值 |
|---|---|---|
| 中心 / 跨度 | 1 GHz / 100 MHz | 1 GHz / 50.78125 MHz |
| 参考电平 | 0 dBm | 0 dBm |
| RBW / VBW | 100 kHz / 100 kHz，手动 | Auto / Equal |
| 扫描 | minSWT (`0`) | minSWT ×4 (`2`) |
| 点数 | 请求 1000；SDK 决定实际值 | 显示 1001 点 |

SWP 使用 Blackman-Nuttall 窗（`1`）、杂散抑制 Bypass、自动衰减 / 前置放大、IF 增益 2 和 Low Noise 增益策略。SDK 实际 RBW、VBW 和点数应从 STATUS 读取，不能根据显示范围和点数推算。

`SET_PRESET` 从 `SWP_ProfileDeInit` 的缓存设备默认值恢复 SWP，并将全跨度归一到型号频率范围，同时恢复固定 RTA 默认值。Frame Avg 回到 `device_default`；SDK 检波器默认值另见 `preset_defaults`。Preset 重置 SDR 采集 / 接收机参数并清除显式 IQS 参考标志（`sdr_ref_set=false`）。SDR 显示尺度归浏览器持有，并请求新的显示拟合。

Preset 保留已确认的采集模式及浏览器重载偏好；重载按存储模式发起请求，并等待后端确认。恢复 SDR 时，即使首份 STATUS 已报告 SDR，也会完整执行一次进入流程：收到已连接的 SDR STATUS 后恢复音频启用偏好，发送调谐命令，再启动纯显示拟合。断开报告会保留这次进入请求，等设备就绪后执行；周期 STATUS 不会重复进入。若 `sdr.ref_set` 已为 true，则保留硬件参考电平，不自动拟合，用户显式点击 Auto 才请求新的决策。

## STATUS 与命令

- 顶层频率、参考、带宽与扫描字段描述当前模式。
- `req.swp` / `req.rta` 保存模式请求；`swp_actual` / `rta_actual` 返回成功配置后的 SDK 实际值；`actual` 指向当前模式实际值对象。
- `config_version` 标识配置变化；`response_to` 将命令响应 STATUS 与命令关联。
- 频率编辑器在周期 STATUS 到来时保留未提交文本；命令成功响应提供实际频率值。
- 增益回读描述当前模式成功配置后的 SDK 实际值；无法获取时为 null。前置放大 `0` 表示 Auto，`1` 表示 Off；Auto 不代表物理放大器已开启。

连续操作从最新期望值累积。频率提交携带 `request_id`，只有匹配最新提交的 ACK/ERROR 才能结束该次等待，随后尚未提交的新草稿不会被覆盖。频率提交独立计时，三秒期限不依赖 `config_version`。匹配 ACK 后显示 SDK 限幅后的实际值。RBW/VBW 的数值与模式共用一次待确认状态，失焦或周期 STATUS 不清除草稿；扫描模式、时间与可见性一起确认或回滚。时钟源与时钟输出也遵循最新意图规则。浏览器仅在收到匹配的成功 STATUS 后执行 Preset 重置并清除采集草稿与待确认状态；失败保留原有界面状态。

RTA 禁用点数、FFT 窗、检波器、帧/网格与杂散控制。RBW 比率仅适用于 SWP；RTA 提供 Auto/手动 RBW，并使用设备支持的选项。

`SET_FREQ` 只接受 `{center, span}` 或 `{start, stop}` 中的一种。中心 / 跨度保留请求中心并缩小跨度以满足设备范围；起止频率要求 Stop > Start，且跨度至少 100 Hz。Full Span 显式选择全频段中点。

RTA 中由 `SET_RTA` 设置中心 / 跨度，跨度映射到 `50.78125 MHz / 2^n`。`SET_RBW`、`SET_VBW`、`SET_SWEEP` 与 `SET_REF` 更新 RTA 自有设置。共享 RF 与参考时钟变更配置当前模式的 Profile。

## 模式切换

浏览器发送 `SET_MODE`，收到 STATUS 后再切换视图；进入 SWP/RTA 时不重新发送本地采集设置。服务停止前一模式的采集，并用目标模式已保存的设置配置设备。返回 SWP 时恢复其独立请求，返回 RTA 时恢复 RTA 请求。

Server 进入为独占操作：`SET_MODE {mode:'server'}` 停止 Web 采集和音频并释放物理 SDK 句柄；点击启动前，服务保持停止。应用仅在子进程已停止时保存 IP 字面量和端口（默认 `127.0.0.1:55132`，保持到 `websad` 重启）。启动和重启重新检查程序、`harogic` factory 及空闲的 SDK 管理槽。停止仍保留 Server 模式。返回频谱请求记住的 `std`/`rta`/`sdr` 图形模式；服务先停止并回收子进程，再重新打开 Web 采集。无法回收时，Server 继续保留设备占用。浏览器刷新、重连和关闭不停止子进程；服务关闭会停止它。

交接要求重新构建的 shim 提供 `san90_session_release_v1`，且 SDK 管理线程空闲。拒绝时返回错误，不提交 Server 模式，但先前采集及其显示流边界的结束不可撤销：STATUS 报告断开并清空实际值/GNSS，之后的采集使用新 epoch。启动失败保留 Server 模式，通过依赖/进程诊断支持显式重试。Server STATUS 和日志字段见 [API](API.md)。

Server 报告 `connected=false`，控制 WebSocket 仍可使用。从 Server 返回 SDR（包括在 Server 中重载浏览器后返回）保留已记住的接收设置，等到已连接的 SDR STATUS 后才重放进入命令并恢复音频启用偏好。断开的模式切换确认不会消耗这次进入请求；后续 STATUS 轮询及普通 SDR 断线恢复也不会再次重放已完成的进入操作。

**SRV** 按钮位于 **SDR** 右侧，打开 **Soapy SRV** 面板；协议模式仍为 `server`。面板显示进程状态、PID、运行时长、退出状态、依赖错误和有界的 stdout/stderr/生命周期日志。暂停只冻结可见日志；跟随滚动新输出，清除隐藏当前本地历史，复制保留原始日志文本。显示级别取自可识别的严重性前缀：stderr 中的 `[INFO]` 仅以中性的 INFO 显示一次，提示中保留原始管道来源。启用动画时，点击切换先用 160 ms 将页面淡出到黑，再发送 `SET_MODE`；确认后在遮罩下切换页面，再以 1440 ms 的 Matrix 字符雨与向下模糊边界揭示目标页面。返回采集时，遮罩最多再等待 1000 ms 的已连接 STATUS，之后仍会显示真实故障。请求被拒绝、超时或控制连接断开时解除遮罩。动画偏好与减少动态效果设置继续生效。视图支持深浅主题、中英文及移动布局。

字符雨参考 Omarchy 的 `ttfx` Matrix 屏保，按列独立随机设置起始高度、启动延时、速度、尾长和重生间隔，保留字符并稀疏随机变换。字符雨与向下推进的模糊边界分层绘制，避免页面揭示过程把所有字符流排成整齐横线。

SDR 偏好包括调谐、采集带宽、解调器、IF 带宽、去加重、音量、静噪和 AGC，以及按模式保存的调谐步进档位、定位方式、频道间距和锚点。普通返回恢复这些偏好。在其他视图中，Shift+点击或“在此收听”以所选频率进入 SDR。没有存储设置时，首次进入从扫频视图推导调谐和解调默认值。收听频率请求串行处理：一条请求在途时，最新目标排队；匹配 request ID 的确认结束当前请求并发送排队目标。拒绝、三秒超时、切换解调模式或采集、Preset 及断线都会取消待处理调谐并恢复已确认频率。窗口失焦只丢弃排队的重复输入。已保存的信号定位偏好在不支持的模式下显示为自由定位，回到 AM/CW 时恢复。离开 SDR 停止播放并保留音频启用偏好。Preset 成功后随其他 SDR 偏好一并清除步进档位表和频道规划。

选择“频道”既切换到频道定位，也在原处展开间距和锚点；“步进”控制独立的设置面板。普通 SDR 图区点击使用自由、频道或信号定位。每次按下指针确定一个归属：坐标轴、标记、缩放、滤波或调谐。Ctrl+图区点击或拖动、已有标记菱形的拖动均归标记处理。开启缩放时，普通图区拖动归框选缩放处理，即使起点在通带或拨盘上也一样。关闭缩放时，Filter 边缘归滤波编辑处理，其他图区拖动自由调谐。标记与缩放不能调谐。切换模式或缩放、pointercancel、Esc 和窗口失焦会取消手势归属，并丢弃待执行的松开动作。

频道和信号定位仅为有效目标显示预览，且只显示一个频率标签。自由定位没有移动预览，信号定位没有常驻提示行。信号定位使用不同的捕获与释放半径，保持已选原生频点。短暂掉信号时，从最后一次局部证据起最多保留预览 300 ms。提交要求当前帧仍支持同一载波，且源、配置和视图未变；目标尚未超时不能单独作为吸附依据。采集频率轴、解调模式或音调变化会清除载波历史。

AM 的 `am_sync` 偏好默认为 false（包络检波），选择其他解调模式时仍保留，恢复 SDR 偏好时一并恢复。Preset 成功后恢复为 false。仅修改此偏好属于实时检波切换，保留采集配置、流身份及源时钟和音频时钟的连续性。

频道命令先校验候选配置，再修改状态。非法 CW pitch 返回 `bad_parameter`，不触发接收器故障。NR 切换保留解码历史和连续的 PCM `audio_index`，源位置前移以跳过被丢弃的降噪器尾部。DRM/DRM+ 保留 NR 偏好，但实际 NR 为 Off。DFN 运行时错误走接收器故障路径；只有初始化失败或运行条件不受支持时才明确选择 Wiener。

共享接收器工作线程故障时，服务设置 `sdr.receiver_error`，并向全部接收器发送 `RECEIVER_ERROR`。音频和解码订阅停止，控件就地显示错误。采集、PFB、fine DDC、原始 IQ、频谱和瀑布继续运行，频谱不显示错误遮罩。调谐与缩放仍可使用。

显式选择 `mode` 或 `demod` 可请求恢复。停止的工作线程退出且失败订阅关闭前，请求返回 `receiver_retiring`，须稍后重试，不会安排自动重启。成功恢复后清除故障，以新的流身份启动接收器，不拼接缺失区间两侧的样本。事件和订阅关闭契约见 [API](API.md)。

只有 STATUS 明确报告健康且已启用频道的流身份已更新时，浏览器才清除接收器故障。AudioContext 创建或恢复错误只影响播放。过期工作线程回调被忽略。本地解码或初始化故障保留到显式重试，或收到健康的新流身份为止。

原始 IQ 与频谱使用有界队列背压，直到明确失败。队列积压时等待，不重新打开采集。SDK 持续停滞时，以原始原因结束采集。恢复须创建新的采集 epoch，不能续接旧时间戳。厂商管理线程卡在 SDK 调用中时，保留该线程，拒绝调用 SDK finish 或重新打开设备。采集和设备故障由全局错误流程处理。主路停用时，重新采集和停止仍保留已启用辅路的尾帧；成帧器只结束已启用频道。

## 参考与显示状态

手动 `SET_REF` 仍在设备端 -160 至 +40 dBm 范围内配置 SDK 前端。SWP/RTA/SDR 独立的本地显示窗口范围为 -200 至 +100 dBm 加外部 Offset。硬件请求将显示目标减 Offset 后限幅；原始请求确认只结束等待，不替换显示窗口。同一限幅硬件目标下的继续移动只改本地显示，并保留原确认期限。拒绝或超时恢复已接受的窗口及其所有权。周期 STATUS 和迹线失效保留手动窗口；确认换模或刷新后恢复当前硬件参考，Auto 和 Preset 释放手动所有权。SDK 实际参考独立上报。修改 Offset 保持迹线位置，不发送硬件命令。能力表边界限制设备域中的 Auto 目标。溢出不会改写手动请求，也不阻止继续编辑。坐标轴拖动预览不依赖新频谱帧。

显式 `AUTO_SCALE` 执行有界恢复与放置操作，最多持续 20 秒、执行 24 步，仅消费当前模式、当前配置下的新观测。遇到 SDK IF overflow（`-12`）时，以当前实际参考为起点提高 10 dB，并受能力表参考上限约束；不改变衰减、前置放大或 IF 增益。取得干净数据后可拟合显示，再由新的干净观测确认结果。手动编辑取消操作。未显式启动 Auto 时，溢出仅告警并保留手动参考。进入模式时的纯显示拟合不修改硬件参考。

幅度偏移仅应用一次，作用于显示绝对电平，包括标记、峰值和绝对测量结果；设备参考与触发阈值仍以 dBm 表示。RTA/SDR 密度可跟随当前处理后的迹线，也可积累 Average/Max Hold 之前的实时频谱帧，均使用原生频率位置与迹线偏移/参考映射。半衰期和命中权重按真实经过时间计算。切换来源、频率轴/几何、迹线选择/模式/平均深度以及 Off 会清除历史；图层可见性和对比度不会。跟随迹线源在 VIEW 时冻结，不衰减也不重复命中；实时频谱源在迹线冻结时继续积累。瀑布上下限必须为有限数且下限小于上限；无效编辑被拒绝，映射变化清除瀑布历史。

SDR 初次加载使用 AVERAGE 16；自定义 64/无限平均在离开并返回该采集类型后保留。Preset 成功后，SDR 的迹线 1 恢复为 AVERAGE 16，SWP/RTA 的迹线 1 恢复为 CLEAR_WRITE，清除平均历史并选中迹线 1。频率、滤波和显示位置分别沿用原有确认及拟合流程。SWP 瀑布仅从新接受的 POWR 数据添加行，使用原始功率及其对应频率网格，采样间隔至少 100 ms；界面重绘不添加行。RTA/SDR 瀑布继续消费原始 RTA 帧。CSV 导出当前采集类型中选定迹线及其匹配频率数组；活动迹线关闭或缺失时提示无数据，不回退到其他迹线。

发起 Preset 及收到对应成功确认时，均取消尚未提交的坐标轴手势。成功确认后恢复 10 dB/格，以及密度默认值：密度+迹线、跟随迹线、0.5 秒半衰期、中等对比度、128 个幅度格、5 CSS 像素显示宽度。首次加载使用相同默认值，已有保存偏好时优先恢复偏好。请求被拒绝或超时则保留当前显示设置。图层和“更多”位于归一化/清除下方，其余密度选项通过“更多”展开；页面加载时默认收起。

AGC 开关与静噪共用一行，以明确的 AGC On/Off 表示状态，与射频静噪和前端增益设置分开。命令带请求编号；拒绝、超时、断线或离开 SDR 都会清除待确认状态，不改变静噪。当前没有可配置的 AGC 速度或目标电平选项。

SWP/RTA 的周期 STATUS 不取消正在按住的坐标轴手势。确认等待期限从松手后计算；预览使用本地窗口边界，确认比较限幅后的原始硬件目标。SDR Preset 等待新频谱数据后执行一次纯显示拟合；Preset 确认中的 `auto_ref: idle` 不会提前结束该拟合。拟合只接受自身请求的确认及结果代次，完成后由手动编辑继续接管显示。

## 测量状态

RTA/SDR 禁用测量控件，处理函数也拒绝相关操作。标准模式下，限制线与信道测量只使用选定迹线经当前模式处理后的绝对电平；归一化迹线显示 N/A，且不产生绝对电平 CSV 行。不回退到其他迹线或原始数据。相对 dBc 结果不叠加幅度偏移。只有 Cal Wnd 重建已有的绝对校准参考；Normalize/Reset 根据所得状态重绘。

PNM 有独立可见的平均设置行。关闭测量后，三个 PNM Set/Apply 控件均被禁用。每次 PNM/Harm Set 都清除旧曲线、表格与累积器，并发送唯一 `session_id`。只有 `response_to` 与 `session_id` 匹配的成功 STATUS 才确认该次应用；结果携带最新已确认会话 ID 才予接受。硬件延迟返回的旧周期保留原 ID，过期或非活动结果不会重新填入显示。

## 触发状态

| 模式 | 自由运行 | 等待 | 命中 |
|---|---|---|---|
| RTA 设备触发 | Bus 源；实时 | Level Capture 已就绪；Stop | 绘制明确完成的数据包后保持 |
| SWP 软件触发 | 实时；Capture | 图形保持实时；Stop | 冻结交叉频率/电平；Capture again |

`Free Run` 或 Escape 释放捕获。SWP 依据电平与边沿比较相邻扫描；网格变化清除交叉历史。RTA 从 STATUS 确认并显示全部已应用触发字段，GET/STATUS 同步不发送控制命令。SWP 禁用高级原生触发控件；SDR、谐波与相噪视图禁用触发控件。外部/定时触发源仅按 API 状态只读显示，不扩展为新的界面操作流程。

RTA2 在每帧 `TRIG` 尾部携带已应用触发状态、配置代次、成功数据包计数与完成元数据。只有连续性明确的有限 Level 捕获才能报告完成；自适应、定时、重复触发或连续性丢失时，完成状态可能保持未知。收到帧或等待 500 ms 均不代表完成。漏触发提示与正常命中区分；模拟数据报告不支持，不能证明硬件命中。保留旧 RTAF 解码以兼容；SDR 仍使用 RTAF。有限 Level 捕获在整个捕获期间累积频谱最大值。先绘制有效且已接受的数据包，再进入保持状态，不提前清空画布。模式切换确认及 Preset 成功后，清除本地就绪/保持、内部阶段与待确认触发状态。

跟踪标记使用当前处理后的 SWP/RTA 迹线。关闭标记时保留其频率与跟踪偏好；坐标轴变化后，先按频率重新定位，再继续跟踪。
