# 常见问题与操作

## 启动与访问服务

在仓库根目录运行项目脚本：

```bash
make native sdk-shim
./build.sh
./run.sh
```

仓库根目录的 `./run.sh` 启动脱离终端的 `websad` 后台进程，无需 systemd，默认使用硬件并监听 `127.0.0.1:8080`。硬件运行所需条件不满足时会报错；`WEBSA_FAKE=1 ./run.sh` 显式选择 fixture 输入。直接运行 `websad` 二进制时，默认端口为 8099，未指定 SDK shim 时使用 fixture 输入；这与根目录启动脚本的默认行为不同。

| 启动变量 | 默认值 | 用途 |
|---|---|---|
| `WEBSA_HOST` | `127.0.0.1` | 监听地址 |
| `WEBSA_PORT` | `8080` | 根启动脚本端口 |
| `WEBSA_INSTANCE` | `websad` | 本仓库的进程实例（`--instance NAME`） |
| `WEBSA_FAKE` | `0` | 显式选择 fixture（`1`） |
| `WEBSA_RUST_IQS_SHIM` | `~/.local/share/harogic-websa/shims/libwebsa_san90_sdk_session.so` | 硬件 shim |
| `WEBSA_STATIC` | 仓库 `frontend` | 包含 `dist/index.html` 的目录 |

`WEBSA_HOST=0.0.0.0 ./run.sh` 开启局域网访问，地址为 `http://device-address:8080/`。产品端点无需认证。`./status.sh` 自动读取保存的主机和端口，输出进程、日志路径与 HTTP 状态；命名实例使用 `--instance NAME` 选择。`./stop.sh` 只停止通过所有权校验的该实例，重复停止成功退出。状态和日志保存在 `$XDG_RUNTIME_DIR/harogic-websa`，没有本用户的可用运行时目录时使用 `${XDG_STATE_HOME:-$HOME/.local/state}/harogic-websa`。

## SDK 所有权与恢复

同一时间只能有一个 SDK 调用访问设备。原生服务保留设备会话，并在管理该会话的线程中串行执行 SDK 调用。启动 WebSA 前须关闭 SAStudio4 和其他 API 客户端，设备不能共享。未显式设置的配置字段继承 SDK Profile 默认值；连续采集需要反复调用 Get。

恢复前先查看 STATUS 错误和实例日志。关闭竞争应用，用 `./stop.sh && ./run.sh` 重启；链路仍不可用时重新插拔 USB。固件卡死可能需要重启系统。启动脚本不会自动重启退出的进程，原生模式所有者负责设备恢复。此处不保证恢复时间。

设备与命令错误显示在频谱右上角的一个诊断栏中，不弹出阻塞浏览器的对话框。相同错误不会累积，不同错误替换当前诊断；悬停频谱可查看完整信息。周期 STATUS、无关命令的成功确认与临时参考电平提示不会清除错误。被拒绝的命令在之后同一恢复范围内的命令成功确认后清除，成功确认的 `SET_MODE` / `CONNECT` 也会清除命令错误。SDR 采集与主路调谐（`SET_SDR`、`SET_SDR_TUNE` 以及主路 `SET_SDR_CHANNEL` 频率编辑）共享恢复范围；其他频道和非频率频道编辑不会清除调谐错误。浏览器为缺少 request ID 的命令补充标识，同时匹配命令与请求 ID，并按发送顺序判断，防止过期确认清除较新的错误。仅重连 WebSocket 会保留诊断并作废旧连接的待确认请求。不含命令身份的错误仍作为设备诊断保留。命令回退和独立的接收器故障恢复规则继续生效。

共享 SDR 接收器工作线程故障会停止全部音频与解码。Decode 行显示“接收器故障”，悬停可查看完整诊断；关闭浮动解码窗格后，错误仍可见。音频和解码连接以“receiver failed”为原因关闭，与慢客户端溢出不同。采集、原始 IQ、频谱、瀑布、调谐和缩放仍可使用。采集和设备故障由全局错误流程处理。

通过现有控件选择解调模式即可重试，也可重新选择当前模式。`receiver_retiring` 表示停止的工作线程尚未退出，或失败订阅尚未关闭，请稍后重试。恢复不会自动进行，替代线程数量有上限。成功恢复后启用新流，不拼接缺失区间两侧的样本。恢复前，STATUS 保留 `sdr.receiver_error`；若再次失败，请查看该诊断与服务日志。

谐波 / PNM 会话运行期间，服务拒绝由 SWP 管理的配置命令，包括频率、参考电平、带宽、扫描、射频前端与参考时钟变更。修改前须先停止测量。

## 频谱与 SDR 操作

SWP 与 RTA 分别保存采集设置。SDK 实际点数和带宽可能与请求值不同。原生 SWP shim 将返回的扫描数据裁剪到请求频率范围，跳过负频率，并将未填充的零功率点标记为 NaN。RTA Auto RBW 使用 SDK 实际值，而非 `span/2000`。参数归属与切换规则见 [MODE_STATE_FLOW.md](MODE_STATE_FLOW.md)。

频率、分辨率、扫描与时钟控件保留最新待确认请求，直到收到匹配的接受或错误；延迟 STATUS 不能覆盖更新的编辑。频率确认采用硬件实际边界，连续跨度步进基于最新请求窗口累积。Preset 仅在匹配的成功确认后清除待处理草稿，失败时保留原界面。RTA 禁用仅适用于 SWP 的点数、FFT 窗口、检波器、网格、杂散与带宽比控件；RTA 带宽仍使用自动或手动方式。

SDR 恢复已保存的调谐、采集带宽、解调器、IF 带宽、去加重、音量、静噪和 AGC。在其他视图中，Shift+点击或“在此收听”以所选频率进入 SDR。调谐请求被拒绝或超时后恢复已确认频率。离开 SDR 停止播放但保留音频启用偏好；Preset 仅在成功确认后重置偏好。非 SDR 的 STATUS 不覆盖 SDR 偏好。WFM 默认启用立体声，原生音频为双声道；显式设置 stereo 为 false 时使用单声道。DRM/DRM+ 编解码音频禁用 AGC、降噪、静噪和去加重控件，音频启用与音量仍可使用。SSTV 的自动/指定模式统一保存，进入 SDR 时重放。`#spectrum.dataset.sdrAudio` 提供音频诊断，包括启用/静音状态、缓冲时间、欠载次数与 RMS。

在 SDR 中，普通点击图区即可按所选定位方式调谐。自由定位使用点击频率。频道定位吸附到频道规划；选择“频道”就在原处展开间距和锚点，没有独立的“网格”按钮。“步进”单独展开调谐步进设置。信号定位从实时原生频谱中选择稳定的 AM 或 CW 载波。有效的频道或信号目标显示一条预览线和一个频率标签。自由定位没有随指针移动的预览线，界面也没有常驻的信号提示行。信号短暂消失时可保留预览，但点击仍须确认当前帧中存在同一载波。

频谱顶部频率滑块用于调谐，通带边缘抓手用于调整带宽；开启缩放后两者仍可使用，其余图区拖动用于框选缩放。关闭缩放时，可沿整条可编辑边缘调整带宽，其余图区自由调谐。通带过窄时可先按“查看”放大。Ctrl+点击/拖动与已有标记菱形用于操作标记。模式或缩放变化、指针取消、Esc 和窗口失焦会取消手势，不提交修改。

SSTV 窗口中，点击清除后显示内联的“全部删除 / 取消”选择，接收仍继续。“全部删除”仅删除所选信道的图片，“取消”保留图片。关闭窗口、离开 SSTV、切换信道或 SSTV 视图/模式，以及断开连接，都会取消待确认操作。

AM 窗口显示恢复的载波频率（MHz）、载波频偏（Hz）、调制度（%）、原始输入电平和最终音频 RMS/峰值（dBFS），以及固定 ±1 满幅刻度的实际最终 PCM 波形。未知值显示“—”。标题只读 badge 显示同步关闭、搜索或锁定；悬停时显示源时序、对齐、延迟和解码错误，AM 不再单独显示时序标签。同步检波开关位于载波频率行右侧。请求待确认时显示“正在开启…”或“正在关闭…”与虚线边框，不提前改变已确认的检波状态，也不显示载波已锁定；请求被拒绝或超时后恢复已确认状态。同步检波开启表示已选择该检波方式，载波锁定还要求 DSP 检测到有效载波。频偏、调制度和输入功率按源时钟平滑。Reload 后进入 SDR 时恢复保存的已确认 `am_sync` 偏好，Preset 成功后将其恢复为 false。流起始、断开连接、离开 AM 或流警告会清除旧指标。

AM 同步检波使用恢复的载波对 IQ 混频，包络检波取 IQ 幅值。载波干净且包络不反转时，两者恢复的节目音频几乎相同，切换未必有明显听感差异。受控过调制或正交干扰能区分这两条路径；同步检波不是通用降噪开关。恢复载波在捕获期间确定相干路径的极性，锁定后保持该极性，避免两种检波交叉渐变时因极性相反而抵消。

音频 RMS 显示按线性功率进行 300 ms 平滑；音频峰值立即上升，以 20 dB/s 速度回落。这些显示响应不改变 PCM、波形样本或原始遥测；流重置或遥测不可用时立即清空仪表。

静噪滑块以 0.1 dB 为步长，并显示请求的 RF 门限。最左端（−160 dBm）关闭静噪；向右提高门限，仅放行更强信号。接收器使用音频 AGC 前的 SDK 频谱调谐点峰值，配合迟滞、保持时间和音频渐变。这是 SDK 标称 dBm 读数，不是积分信道功率。方向键按步进框显示的步长调谐，Shift 与 Ctrl 分别切换粗、细档；各档按解调模式记忆，与采集带宽无关。点击步长快选按钮后可立即按左右键调频；数值输入框保留自身编辑按键，输入框、对话框或数字键盘聚焦时快捷键不生效。

AGC 开/关用于自动调整解调后的收听电平；关闭后使用固定增益，不改变射频前端或静噪门限。目前不提供速度或目标电平设置。开关命令只修改 `agc`；匹配的确认结束请求，拒绝、超时或退出会话清除待确认意图。

其他接收器可提供更多 AGC 控件。[FlexRadio 的 SmartSDR 说明](https://helpdesk.flexradio.com/hc/en-us/articles/360029494371-How-Does-the-Automatic-Gain-Control-AGC-Function-in-SmartSDR) 将 FAST/MED/SLOW 定义为强信号之后的增益恢复速度，将 AGC-T 定义为最大可用增益。这些设置取决于接收器实现；本应用的固定音频 AGC 尚不提供这些参数。

迹线检波器选择只适用于 SWP，在 RTA 或谐波 / PNM 测量中会被拒绝。Auto Sample 随信号类型选择；Sample、Pos Peak、Neg Peak 和 RMS 使用固定检波器。Auto Peak 面向脉冲信号，通过 API 提供，不在 UI 中提供。比较检波结果时保持跨度、RBW 和点数不变。

## 参考电平与溢出

设备输入端的手动 `SET_REF` 请求范围仍为 -160 至 +40 dBm。SWP、RTA、SDR 的本地 Ref 显示窗口独立，范围为补偿前 -200 至 +100 dBm，再加外部 Offset。Offset 为零时，输入或拖到 +100 会显示 +100，而硬件请求为 +40；输入 +110 则显示限制为 +100。在 +90 和 +100 之间移动复用同一个硬件请求，包括该请求仍待确认时。匹配的原始电平确认接受显示窗口，不会将它改回 +40；拒绝或超时恢复最后已接受的窗口。修改 Offset 同步平移边界、纵轴和绝对电平读数，保持迹线位置，不发送硬件命令；到达 +100 不需要 Offset。SDK 实际参考 `ref` 独立上报，悬停 Ref 输入框或读数可比较。Auto 替换手动窗口；切换模式或刷新页面后按当前硬件请求加 Offset 恢复。Preset 清除手动窗口所有权，SDR 在新数据到来后拟合一次。IF 溢出只告警，不阻止编辑。修改 Ref 保留增益选择。SDR 的 `sdr.ref`、SWP 的 `req.swp.ref` 和 RTA 的 `req.rta.ref` 均保存未补偿的设备请求。谐波/PNM 测量期间禁用 Level 控件。

SWP 在 IF 溢出时保留 SDK 返回的完整新扫描，并继续显示告警；饱和数据可能不准确。若 SDK 未返回完整新扫描，则不发布替代帧，也不把旧缓冲重复当作新数据。提高 Ref 可以解除告警，手动操作期间程序不会自行抬高 Ref。

显式 `AUTO_SCALE` 启动有界会话（20 秒，最多 24 步），仅由同一模式、同一配置下的新采集证据推进。SDK IF 溢出告警 `APIRETVAL_WARNING_IFOverflow`（-12）允许从当前 SDK 实际参考电平增加 10 dB，最高不超过上报的参考上限；实际值已高于上限时绝不向下调整。衰减、前置放大、中频增益及策略保留用户选择。与告警一起返回的有效 IQ 会被保留。普通无数据或等待触发不会抬高参考，手动操作也没有后台参考调整。

Auto 仅根据无溢出的频谱拟合，配置变化后还须取得新的无溢出频谱才能确认完成。SDR 显式 Auto 可重配 IQS 以恢复溢出；进入 SDR 使用 `display_only:true`，不修改硬件。手动配置、频率、模式或 Preset 变更会取消旧会话并清除旧目标。`auto_ref` 提供进度与结束原因，包括 limit、stalled、failed、no_data 和 timeout；未成功完成时目标为空。完整结果结构见 [API](API.md)。

幅度偏移仅应用一次，作用于显示绝对电平（坐标轴、标记、峰值和信道读数）。dBc 等差值仍为差值；设备参考、衰减与触发阈值保持仪器单位。实际增益按当前 SDK 模式回读，缺失字段保留为 null。前置放大器 Auto/Off 表示所选策略，不代表物理开关状态。瀑布电平范围必须有限且有效；映射变化会清空历史，即使已暂停。

衰减、预放策略、IF 增益档位和增益策略分别提交、分别确认。旧命令回复不会确认较新的选择；拒绝、超时或断线会清除待确认值。实际回读描述 SDK 已配置的前端参数。预放 Auto 表示策略，不证明物理开关状态；IF 档位也不同于 SDR 音频 AGC。

## 参考时钟与固件

- `ReferenceClockSource`：0=内部，1=外部且失锁时回退，2=内部 + DOCXO，3=强制外部。Premium 时钟是否可用取决于设备。
- SAN-90 外部参考输入为 10 MHz；原生 shim 将 `ExternalSystemClockFrequency` 与外部参考频率设为 10 MHz。
- 参考输出支持取决于型号。时钟变更配置当前 Profile；RTA 保持 RTA。
- 没有有效外部参考时不要选择 `external_forced`。`SystemClockSource=External` 是另一项厂商设置，WebSA 不提供该选项。
- GNSS 1PPS 校准需要真实且锁定的 1PPS 输入；没有信号时厂商调用可能阻塞。
- 部分固件将 `RefClkFreqOffset` 报告为零；零值不能证明时钟准确。可用时应使用计算得到的校准结果。
- SAN-45/60/90 标称频率上限分别为 4.5/6/9 GHz，下限为 9 kHz；规格与支持能力因型号而异。

## 触发与测量问题

RTA 使用设备触发；SWP 软件触发在相邻扫描发生阈值交叉前保持实时显示。防抖、延迟和预触发时间仅适用于 RTA。RTA 请求设置与 SDK 实际回读分别保存，完整帧绘制完成后才保持捕获。厂商超时本身不能证明正在等待触发；不支持或未知的捕获状态会明确显示。Fixture 输入不模拟硬件命中。确认命中后保持冻结，直到 Free Run 或 Escape；Auto Scale 不解除已就绪触发。

PNM 结果随连续 Get 调用增量更新。100 Hz 与 10 MHz 偏移边界附近可能不准确，可用最大偏移两倍的扫频跨度交叉检查。PNM 典型最小输入功率为 -50 dBm。

每次谐波/PNM Set 都会清空旧曲线、表格与累积结果。结果须匹配最新已确认命令的会话，旧采集周期不能填入新测量。PNM 平均有独立控制行，关闭 PNM 后其全部 Set/Apply 操作均禁用。限制线与信道测量使用所选的已处理绝对电平迹线；归一化迹线不提供这些绝对读数或绝对电平 CSV 导出。RTA/SDR 禁用这些测量控件，返回标准模式后恢复。dBc 读数不叠加幅度偏移。

n-dB 键盘用于编辑以逗号分隔的整数阈值列表。退格键删除光标处字符，C 清空输入，小数点键输入逗号；OK 整理首尾及连续重复的逗号。如果没有 1–60 dB 范围内的阈值，输入旁显示内联错误并保留上次测量；修正输入后错误消失。

开发检查与硬件验证流程见 [DEVELOPMENT.md](DEVELOPMENT.md)；当前限制见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
