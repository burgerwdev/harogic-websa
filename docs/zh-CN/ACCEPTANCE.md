# 1.12.15 验收 — 2026-11-08

## 变更与回归

- multimon、rtl_433、OnAir、RTTY、GNSS 共用 PreparedDecoders 准入、恢复及收尾机制。准备失败只影响对应信道，健康邻路继续运行。
- 管道输入保留上限为 32 MiB、1,024 块，包含执行中输入。fine 和处理器按实际采样率／格式计算两秒字节预算，限定为 4–64 MiB；处理器另限两秒媒体时长，两种队列均限制为 1,024 项，fine 包含一执行块。
- 数字接收不受伴随音频静噪影响。没有模拟监听链的模式报告 `squelch:null`；故障、恢复及积压优先于等待状态。
- 解码和概览订阅已有接收机。已启用信道无需打开窗口即可启动接收。Current 与同频保存接收机分别拥有处理链及外部解码进程。
- 宽带模式默认过渡带为 max(1 kHz, 占用带宽 / 8)，ADS-B 为 225 kHz；现有显式配置继续作为显式参数。
- 诊断／原始 JSON、数据流／IQ 传输和录制来源／文件详情提供复制按钮，支持普通 HTTP 剪贴板回退。
- 离线工具接受管道 stdin；生成的 FT4／WSPR 样本可显式调度至完整主机 UTC 时隙，普通录音仍不能任意重排时隙回放。

## 实测验收

| 输入／检查 | 结果 |
|---|---|
| RTTY／反极性 | 完整 ITA2 文本、数字、标点及末尾换行；每种极性 935,604 个复样本，48 kS/s。 |
| APRS | 三个生成的 AX.25 帧：N0CALL-1 发往 APRS，WEBSA APRS TEST，49.05833°、−72.02917°。 |
| FT4／WSPR | 生成完整 UTC 时隙，分别解出 CQ K1ABC FN42／K1ABC FN42 30。 |
| GPS | 合成 90 秒场景，2.6 MS/s、234,000,000 个输入复样本；196 个有效 PVT 快照、132 条导航记录。 |
| 浏览器／音频 | 实际复制内容通过；−6 dB EQ 幅度比约 0.50，完全右声像，全部静音输出 PCM 为零，旁路／解除静音后恢复；本地监听操作不写服务配置。 |
| 信道生命周期 | 三路原生信道并发，16 次模式切换、四次删除重建；健康邻路配置及流身份保持。 |
| 无窗口接收 | 仅 HTTP 的 fixture 回归创建第二路接收机；没有浏览器或输出订阅时两路仍处理并推进。 |
| 双路硬件 ADS-B | SAN-90，原 Current 和保存信道的 1090 MHz 配置，采集 7.8125 MS/s；CI 期间观测 304 秒，积压最高 0.87 秒并排空，结束时两路 active，中断／故障均为零，流身份保持且时钟推进。 |

已知载荷验证接入链路；持续十六信道射频容量、灵敏度及被动 GPS 天空接收尚未验收。本次没有射频发射。
